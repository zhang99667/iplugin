# SVG 技术图风格系统

## 默认定位

默认画“朴素、清楚、像技术文档里应该出现的图”，而不是暗色科技感海报。优先让读者看懂结构、方向和差异。

默认风格：

- 白底或浅灰底。
- 灰阶线框为主。
- 少量强调色只用于主流程、风险、成功、外部依赖等必要语义。
- 不使用霓虹、强渐变、发光、复杂阴影和装饰性背景。
- 不把调色盘当成硬约束；调色盘只是为了避免临时乱选颜色。

## 推荐色彩

先使用中性色，再按需要加 1 到 3 个强调色。

中性色：

| 用途 | 色值 |
| --- | --- |
| 页面背景 | `#FFFFFF` |
| 轻背景 / 分组底 | `#F8FAFC` |
| 分隔背景 | `#F1F5F9` |
| 主文字 | `#0F172A` |
| 正文 | `#334155` |
| 辅助文字 | `#64748B` |
| 边框 / 连接线 | `#CBD5E1` |
| 次级连接线 | `#94A3B8` |

可选强调色：

| 用途 | 色值 | 使用建议 |
| --- | --- | --- |
| 主流程 / 当前重点 | `#2563EB` | 一张图最多一条主路径 |
| 成功 / 推荐 / 完成 | `#16A34A` | 只标结论或目标状态 |
| 关键 / 注意 | `#D97706` | 决策点、关键约束 |
| 风险 / 错误 | `#DC2626` | 异常路径、阻断、反例 |
| 外部系统 / 扩展 | `#7C3AED` | 第三方、可选能力、平台层 |

色彩规则：

- 能用黑白灰讲清楚，就不要加颜色。
- 一张图优先只用 1 个强调色；确实有风险/成功对照时最多 3 个。
- 同一篇文章中，相同语义尽量复用同一强调色。
- 不用大面积彩色填充；更推荐细边框、左侧短色条、标题小标签或箭头颜色。
- 如果上游 HTML 报告已有视觉系统，可借用它的主色，但仍保持少色。

## 字体和字号

字体栈：

```css
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC", "Noto Sans CJK SC", "Segoe UI", sans-serif;
```

字号底线：

- 主标题：`24px` 到 `30px`，最低 `22px`。
- 副标题 / 说明：`13px` 到 `15px`。
- 节点标题：`15px` 到 `17px`。
- 节点正文：`13px` 到 `15px`，最低 `12px`。
- 小标签 / 编号：`11px` 到 `12px`，只放短词。

文字规则：

- SVG 文本不自动换行，必须手工用 `<tspan x="..." dy="...">` 分行。
- 中文估宽按 `字数 * 字号`；中英混排按更保守的中文宽度估算。
- 节点内左右 padding 至少 `16px`，标题和正文间距 `8px` 到 `12px`。
- 编号和标题之间的视觉距离不超过 `30px`，避免标题像脱离了步骤。

## 画布和节点

画布按内容选择，不固定套同一个尺寸：

- 技术长文横图：`viewBox="0 0 1200 675"`，只适合有上下两层、分组容器或较多内容的图。
- 单行流程、生命周期、横向 3 到 6 个节点：优先使用较矮画布，例如 `viewBox="0 0 1200 360"` 到 `1200 460`。
- 信息更密集的报告图：`viewBox="0 0 1200 720"`，只在确实需要更多垂直信息时使用。
- 竖向流程：`viewBox="0 0 900 1100"` 或按步骤数扩展高度。
- 背景 `<rect>` 的宽高必须和 `viewBox` 对应；内容完成后根据最上/最下元素再裁掉多余空白，保留外边距即可。

布局间距：

- 外边距：至少 `40px`，标题区下方至少 `28px`。
- 并列节点间距：至少 `28px`，复杂箭头通过的 gutter 至少 `36px`。
- 节点圆角：`6px` 到 `8px`。普通架构图不需要大圆角。
- 阴影：默认不用；如果需要层级，只用非常轻的阴影。
- 分组容器：浅灰底或虚线边框即可，不做厚重面板。

节点结构：

1. 白色或浅灰矩形。
2. 细边框。
3. 可选编号、小标签或左侧短色条。
4. 标题。
5. 1 到 3 行正文短句。

## 可读性底线

- 不使用负字距。
- 不用低对比度浅灰正文。
- 不把文字放在复杂背景上。
- 不用 8 个以上节点挤在一屏；信息过多时拆成多张图。
- 不用过细线条。边框至少 `1px`，主箭头至少 `2px`，重要箭头 `2.5px`。
- 不为了“高级感”添加渐变、光效、背景纹理或大面积色块。
