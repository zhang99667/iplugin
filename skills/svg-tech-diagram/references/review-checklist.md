# SVG 技术图自审清单

交付前必须先渲染 PNG，并真实查看渲染结果。不要只读 SVG 源码判断。

## A 级硬指标

任一项失败都必须修改 SVG、重新渲染、再次查看 PNG。

- PNG 成功渲染，画面不是空白、裁切、错位或字体缺失。
- 画布高度和内容匹配；单行流程图、横向生命周期图等不能因为沿用 `1200x675` 而在下方留下大面积空白。
- 垂直布局没有上挤下空；主体包围盒上下留白大致平衡，下方空白不能比上方多 `80px` 以上或超过上方空白的 2 倍。
- 主标题字号不低于 `22px`，正文不低于 `12px`，普通读者在公众号宽度或分屏下能看清。
- 中文、英文、数字都没有越出节点、贴边、互相遮挡或对比度不足。
- 所有长文本已手工换行，节点内左右 padding 至少 `16px`。
- 所有文字块都有明确占位：节点正文、箭头标签、图例、底部说明没有进入其他节点、连线或容器边框的包围盒。
- 标题、请求路径、阶段标签、节点和说明区各自占据明确垂直 band；顶部没有文字堆叠、标签贴标题或标签压到节点。
- 底部说明和图例位于独立说明区，和最近的节点边框、箭头或分组容器至少保持 `24px` 间距。
- 箭头端点落在节点或容器边缘，不进入标题、正文、徽章或图标区域。
- 箭头路径不穿过文字；跨容器箭头没有被节点遮住；箭头 marker 清晰可见。
- 节点、编号、标题、正文之间的视觉间距稳定，编号和标题距离不超过 `30px`。
- 外边距至少 `40px`；节点之间留有足够 gutter，布局没有拥挤感。
- 颜色服务信息结构，不为了科技感添加渐变、发光、背景纹理或大面积色块。
- 强调色数量克制，默认不超过 3 个；同一语义尽量不换色。
- 图中文字都是短句、关键词或状态名，没有把正文段落塞进 SVG。
- Markdown/HTML 嵌入片段能指向正确文件；HTML 报告内联 SVG 不依赖外部 CSS、JS 或字体文件。

## B 级阅读质量

这些项不一定阻断交付，但失败时优先优化。

- 读者能在 3 秒内看出入口、主流程、分支和结论。
- 图的标题回答“这张图在讲什么”，不是泛泛写“架构图”。
- 节点标题使用业务或代码里的真实名词，避免“模块 A”“模块 B”这种占位符。
- 主路径视觉上最强，辅助关系退后，风险/异常不抢走整张图注意力。
- 并列节点尺寸一致；同类元素的圆角、边框、字号一致。
- 箭头标签离线条有 `8px` 到 `12px` 间距，不贴线。
- 如果图超过 7 个节点，已考虑拆成两张图或改成分层/泳道结构。
- 图下正文能补充细节，图内没有解释性长句。

## C 级交付检查

- SVG 含 `<title>` 和 `<desc>`，便于可访问性和后续维护。
- SVG 使用 `viewBox`，没有只靠固定 `width/height`。
- CSS 内联在 SVG 内，不依赖页面全局样式。
- 文件名能表达图意，例如 `render-loop-architecture.svg`，不要叫 `diagram-final-final.svg`。
- 同一篇文章多张图的画布比例、背景、节点风格和基本颜色规则一致。

## 用户反馈映射

把用户反馈转成下一轮重点检查项：

| 用户反馈 | 优先排查 |
| --- | --- |
| “字太小 / 看不清” | 字号底线、正文颜色、节点 padding、画布是否信息过密 |
| “文字遮挡 / 压线 / 贴到卡片上” | 文本块包围盒、底部说明区、节点高度、行高、z-order、是否需要扩大 viewBox |
| “箭头乱 / 穿过去了” | 箭头端点、路径 gutter、z-order、是否需要改成泳道或分层 |
| “有点挤” | 外边距、节点数量、是否拆图、是否删减正文 |
| “空白太多” | viewBox 是否按内容收缩、背景 rect 是否同步尺寸、上下外边距是否只保留必要空间 |
| “下面很空 / 上面很挤 / 文字堆在一起” | 主体包围盒、标题/标签/主体/说明区 band、上下留白差值、是否需要整体下移主体或裁短 viewBox |
| “太花 / 太科技感” | 是否使用多余渐变、发光、背景纹理、大面积色块或过多强调色 |
| “看不懂顺序” | 编号、主路径、箭头方向、标题是否表达动作 |
| “和上一篇不像一套” | 背景、圆角、线框、字号、节点样式、强调色是否复用 |
| “公众号里糊了” | 是否交付 SVG 而不是位图、Markdown/HTML 是否引用了 SVG |
| “嵌到 HTML 后样式变了” | 是否内联 CSS、class 是否被页面覆盖、是否依赖外部字体 |

## 通过口径

最终回复前用一句内部判断确认：

```text
已渲染 PNG、已查看预览、A 级项全过，B/C 项无明显发布风险。
```

如果做不到这句话，不能把图说成“已完成自审”。
