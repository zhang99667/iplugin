# v0.9.0

## 目标

把“结合互联网上最优秀的内容”从只能手动调用的 slash command，升级为模型可根据语境主动触发的通用 skill。

## 变更清单

- 新增 `skills/best-of-web/SKILL.md`
  - 定义 `best-of-web` skill 的触发边界、适用场景和不适用场景
  - 支持用户用“结合互联网上最优秀的内容”“找权威资料”“最佳实践”“高质量参考”等语义触发
  - 要求优先使用一手来源、官方文档、原始论文、权威机构资料和高信号专家文章
  - 要求交叉验证、综合输出、标注来源，并说明冲突、不确定性或证据薄弱处
- 保留并收敛 `commands/best-of-web.md`
  - 命令作为手动强制入口
  - 具体执行规则委托给 `skills/best-of-web/SKILL.md`
- README 新增 `best-of-web` skill 说明与 `/best-of-web` 命令说明
- 插件版本升级到 `0.9.0`，同步更新 Claude Code 与 Codex manifest

## 架构决策

- 将 skill 作为真正的触发面：模型只有看到 skill description 和触发边界，才能根据当前语境主动判断是否调用。
- slash command 只保留为显式覆盖入口，避免用户想强制联网精选时没有直接命令可用。
- 不把搜索逻辑绑定到特定搜索引擎或工具名称；执行时由当前模型环境选择可用的联网能力。
- 触发边界刻意排除普通代码问答、本地多源证据收集和用户明确不要联网的场景，避免过度触发。

## 排除项及原因

- 不新增脚本：这个能力依赖模型判断、搜索和综合，不需要确定性本地脚本。
- 不改造 `delegated-search`：它服务多源证据收集与委派，`best-of-web` 服务高质量公开互联网内容精选。
- 不默认生成 HTML 报告：输出形式仍由用户请求决定，`best-of-web` 只负责来源质量和综合质量。
