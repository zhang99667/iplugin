# v0.22.37 - HTML Report 代码块语言/复制同位切换

## 目标

让代码块右上角只占一个稳定视觉位置：未操作时显示代码语言，鼠标悬停或键盘聚焦代码块时切换为复制按钮，减少两个控件并排造成的拥挤

## 变更清单

- `.code-lang` 与 `.copy-btn` 共用工具栏右上角同一槽位
- 默认显示语言标签，代码块 hover 或 `focus-within` 时隐藏语言并显示复制按钮
- 触摸设备无 hover 时默认显示可操作的复制按钮
- 只有 code-block runtime 初始化后才启用复制/语言切换视觉态，禁用 JavaScript 时保持语言标签和源码可读
- 打印模式恢复显示语言标签并隐藏复制按钮
- `check_html_report.py` 增加同位切换 CSS 门禁
- 更新 code-block 组件测试、Gallery、视觉契约和组件契约
- `html-report` skill 从 `0.7.15` 升级到 `0.7.16`，插件从 `0.22.36` 升级到 `0.22.37`

## 架构决策

- 保留现有 `.code-toolbar` DOM 顺序和复制 runtime，避免改变静态报告结构及旧报告迁移逻辑
- 用 CSS 的透明度、可点击状态和同一绝对定位槽位完成切换，不增加浏览器运行时状态
- 保留键盘聚焦路径，确保复制按钮仍可通过 Tab 访问并在焦点进入时显示

## 排除项及原因

- 不修改 `highlight_code.py` 的输出字段和语言规范化逻辑，语言标签内容与复制文本行为保持不变
- 不修改复制 API、剪贴板回退和成功提示，避免把视觉改动扩大为交互协议变更
- 不把 Diff viewer 的文件标题改成语言/复制槽位，避免与 diff 语义标签重复
