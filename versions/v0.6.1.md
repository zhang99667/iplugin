# v0.6.1

## 目标

优化 `html-report` 中源码文件位置的展示方式。报告中的 `rg` 搜索结果、代码评审问题定位和源码链路位置，应该既保持可读，又能直接从 HTML 一键跳转到 IDEA。

## 变更清单

- `html-report` 升级到 `0.2.5`
- 新增文件定位链接规范：统一展示为 `{path}:{line}` 或 `{path}:{line}:{column}`
- 有绝对路径时要求生成 `idea://open?file=...&line=...&column=...` 链接
- CSS 模板扩展 `.path file-link` 的 hover 样式，保持文件 chip 的视觉一致性
- 完成前检查加入 IDEA 跳转链接校验

## 架构决策

- 将文件路径、行号、列号合并为一个可点击 chip，避免路径和行号分散导致读者难以复制或定位。
- `idea://open` 链接只在有可靠绝对路径时生成；如果只有相对路径且无法还原，不编造不可用链接。
- 路径展示文本保留原始可读形式，href 中再做 URL 编码，兼顾可读性和协议兼容性。

## 排除项及原因

- 不引入额外 JS 自动转换路径，避免报告依赖运行时代码才能定位。
- 不强制为非源码路径生成 IDEA 链接，例如普通网页链接、数据文件摘要或无法确认位置的日志片段。
