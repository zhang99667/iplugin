# v0.18.0 — 商业 AB 透视表生成 skill

## 目标

把外部维护的 `nad-acx-pivot-table` skill 纳入 iPlugin，让商业 AB 实验数据可以直接从 CSV/TXT/XLSX 生成 Excel 原生数据透视表，并复用同一套 Claude Code / Codex 插件分发链路。

## 变更清单

- 新增 `skills/nad-acx-pivot-table/`。
- 引入 `pivot_tool` 零外部依赖脚本，支持读取 CSV/TXT/XLSX、合并多文件、写出带原生 pivot cache / pivot table 的 xlsx。
- 引入 `commercial_ab_test` 预设，覆盖 `exp_id`、`event_day`、`eshow`、`click`、`charge`、`tcharge`、`conv` 及 `ectr`/`cvr`/`evr` 派生指标。
- 引入 `references/config_schema.md` 和 `references/ooxml_pitfalls.md`，把长配置说明和 OOXML 注意事项放入 progressive disclosure。
- 补齐本仓库要求的 `version` 与 `tags` frontmatter，并将用户配置路径调整为跨客户端的 `~/.config/iplugin/nad-acx-pivot-table/user_config.json`。
- README、CHANGELOG、Claude / Codex manifest 增加商业 AB 透视表能力说明和触发关键词。
- 插件版本升级到 `0.18.0`。

## 架构决策

- 按新增通用能力处理为 Minor 版本，而不是 Patch。该 skill 新增了用户可见能力和一套 bundled CLI。
- 保留源 skill 的脚本实现，不在本次迁入中重写 pivot OOXML 生成逻辑，降低引入回归的风险。
- 用户偏好配置不写入 skill 安装目录，改用 `~/.config/iplugin/...`，避免 Claude / Codex 插件缓存路径差异导致配置不可持久化或污染仓库。
- 继续把 OOXML 陷阱和自定义配置 schema 放在 `references/`，主 `SKILL.md` 只保留触发、核心流程和必要导航。

## 排除项及原因

- 不新增 slash command：该能力由 skill description 触发，命令层不需要重复承载流程。
- 不在本次迁入中新增更多商业预设：当前先保留源 skill 的 `commercial_ab_test`，避免没有实际数据验证的模板膨胀。
- 不把 `pivot_tool` 抽到仓库顶层 `scripts/`：它是该 skill 的专属执行资源，放在 bundled `scripts/` 中更符合 progressive disclosure。
