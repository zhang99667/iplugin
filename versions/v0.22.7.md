# v0.22.7

## 目标

将 `html-report` 离线批注功能的正式名称从“审核模式”调整为“评论模式”，让页面名称与用户实际进行提问、批注和反馈的行为一致。

## 变更清单

- 页面模式标签、保存按钮、提示和导出确认文案统一使用“评论模式”“评论结果”和“评论版”。
- `SKILL.md`、评论模式 reference、视觉规则、README、manifest 与 eval fixtures 同步新名称。
- 校验脚本检查“评论模式”和“保存评论结果到 HTML”，防止生成页面回退到旧名称。
- `html-report` skill 版本升级到 `0.4.1`，插件版本升级到 `0.22.7`。

## 架构决策

- 只迁移中文产品术语，保留 `annotation-mode` 目录、`inject_annotation_mode.py`、`AgentQuestionPack`、`--require-review-pack`、DOM id 和 `review` 数据字段，避免破坏已有 HTML 与自动化调用。
- 继续识别用户输入中的“审核模式”旧称，但新生成页面和交付说明统一输出“评论模式”。

## 排除项

- 不回改历史 CHANGELOG 和旧版本规划中的原始术语，保留版本事实。
- 不迁移本地存储 key、内嵌包 schema 或发布版剥离标记；本次不是数据协议升级。
