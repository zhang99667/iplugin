# v0.21.9 - delegated-search 主线程上下文预算

## 目标

收紧复杂任务委派后的主线程行为，避免子 Agent 已经承担搜索和链路追踪时，主线程仍执行同范围宽泛搜索，导致上下文消耗和结论噪声上升。

## 变更清单

- `skills/delegated-search/SKILL.md`
  - skill 版本升级到 `0.1.5`。
  - 工作流中明确子 Agent 运行时主线程只做不重叠工作，不重复执行已委派范围的大搜索或全链路阅读。
  - 新增“主线程上下文预算”小节，要求主线程优先使用精确标识符、`rg -l`、入口文件和少量证据抽查。
  - 明确命令输出超过 200 行、被截断或无关命中过多时，应立即收窄查询或交给子 Agent。
- `.claude-plugin/plugin.json` / `.codex-plugin/plugin.json`
  - 插件版本升级到 `0.21.9`。
- `CHANGELOG.md`
  - 新增 `0.21.9` 版本记录。

## 架构决策

- 继续把约束放在 `delegated-search` 主 skill 中，因为这是委派工作流的核心行为，不适合拆成额外 reference。
- 仅升级 patch 版本，因为本次是已有复杂任务委派能力的指令优化，没有新增 skill、command 或用户入口。
- 保留仓库规范要求的 `version` 和 `tags` 顶层 frontmatter，优先满足本插件的 `validate-plugin.py` 与发布流程。

- 不修改 README 或 manifest 关键词。用户可见能力名称和触发词没有变化。
