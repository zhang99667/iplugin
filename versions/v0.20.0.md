# v0.20.0 - Android mock 自测验收 Skill

## 目标

把 Android mock 自测沉淀为通用 iPlugin skill，支持根据 mock 文档、测试用例、scheme 脚本和 mockserver 配置逐 case 执行验收，并产出链路分离、证据可追溯的验收报告。

## 变更清单

- `skills/android-mock/SKILL.md`
  - 新增 `android-mock` skill。
  - 约定 mock 方案和验收结果分开，避免把执行方案、case 结果和证据材料混在一张密集表里。
  - 要求多条链路分别验收，例如宿主 App 链路、SDK 链路、内部入口和外部 scheme 入口。
  - 明确每个 case 必须有状态和证据，状态覆盖 `通过`、`通过*`、`差异`、`失败`、`未测`。
  - 沉淀截图、录屏、logcat、mockserver 日志、无请求观察窗口等证据采集规则。
  - 对接 `html-report` 的媒体证据结构，推荐把图片/视频放入证据附录而不是塞入结果表格。
- `README.md`
  - Skills 表新增 `android-mock`。
  - 插件简介补充 Android mock 自测验收能力。

  - 新增 `0.20.0` 版本记录。

## 架构决策

- skill 名称使用 `android-mock`，短于 `android-mock-acceptance-test`，方便记忆和手动触发；验收闭环语义放在 description 和正文里表达。
- 本次作为新增用户可见能力，按维护指南的 SemVer 规则升级 minor 版本到 `0.20.0`，不使用 patch 版本。
- 不新增独立 command。该能力更适合通过 skill 触发，避免同名 command 和 skill 复制两份流程。
- 不在 skill 中固化具体项目、卡片号、接口路径或号码，只保留可迁移到不同 Android mock 需求的执行流程和采证标准。
- HTML 媒体证据只引用 `html-report` 的标准结构，不在本 skill 内重复维护完整 HTML 模板。

## 排除项及原因

- 不内置 mockserver、scheme 生成或 adb 自动化脚本：不同项目的入口协议、包名、case 参数和 mockserver 实现差异较大，skill 先提供通用执行约束。
- 不要求每个验收都必须输出 HTML：用户只要求 Markdown 或对话内结论时，可以按同样证据结构输出轻量报告。
- 不包含一次性项目验收结果：具体需求的验收报告应保留在需求交付目录，不进入通用插件 skill。
