# v0.11.0

## 目标

新增 `html2md` skill，把本地 HTML 文件、`file://` URL 或用户粘贴的 HTML 内容转换成 Markdown，沉淀刚刚手工验证过的 HTML → Markdown 工作流。

## 变更清单

- 新增 `skills/html2md/SKILL.md`，定义触发边界、默认流程、输出路径策略和校验步骤。
- 新增 `skills/html2md/scripts/html2md.py`，使用 Python 标准库解析 HTML 并输出 GitHub Flavored Markdown。
- 更新 README、CHANGELOG 与 Claude/Codex manifest，使插件能力清单包含 HTML 转 Markdown。

## 架构决策

- 转换逻辑放在 skill 自带脚本中，而不是要求模型手工重排全文；这样能稳定保留标题、列表、表格、代码块和 diff 表格。
- 脚本只依赖 Python 标准库，避免在受限网络或新环境中安装 `pandoc`、`html2text` 等外部依赖。
- 远程网页、登录态网页不在脚本中直接抓取；先由浏览器/Chrome 能力保存成本地 HTML，再进入本 skill。

## 排除项

- 不做 Markdown → HTML；该方向继续由 `html-report` 处理。
- 不追求像 Pandoc 一样覆盖所有 HTML 语义；当前目标是技术方案页、HTML 报告和常见单文件文档的高可信转换。
