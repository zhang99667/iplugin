# v0.19.9 - SVG 技术图文字防遮挡规则

## 目标

修复 `svg-tech-diagram` 生成技术图时，底部说明、图例、箭头标签等自由文字可能贴近或压到节点卡片的问题。规则应把遮挡风险前置到布局阶段，而不是只依赖渲染后肉眼微调。

## 变更清单

- `skills/svg-tech-diagram/SKILL.md`
  - skill 版本升级到 `0.1.2`。
  - 最短执行流程新增“布局预算”步骤，要求先为节点、正文、箭头标签、图例和底部说明估算包围盒。
  - 绘图纪律新增自由文字独立预留区和 `24px` 最小视觉间距要求。
- `skills/svg-tech-diagram/references/style-system.md`

- `skills/svg-tech-diagram/references/svg-patterns.md`
  - 新增文本和说明区占位示例，明确底部说明不能放进主体内容剩余缝隙。

  - A 级硬指标增加文字块包围盒和独立说明区检查。

## 架构决策

- 不新增单独 lint 脚本。SVG 文本真实宽高受字体、渲染器和中英混排影响较大，静态脚本很容易产生误判；当前阶段优先用明确的手工包围盒预算和 PNG 自审闭环约束输出质量。
- 把底部说明、图例、箭头标签视作独立文字块处理。它们不是节点内部内容，必须拥有自己的注释区或通道，避免漂在节点边缘附近。
- 保持现有朴素浅色技术图风格，不引入新的视觉系统。

## 排除项及原因

- 未改变 `render_svg.py`：本次问题是布局规则缺口，不是渲染能力缺失。
- 未更新 README 和 manifest keywords：插件对外能力没有新增，只是既有 SVG 技术图质量规则的 patch 优化。
