# v0.19.14

## 目标

补强 `commercial-sql-writer` 对落地页性能和抵达率 SQL 的字段识别能力，避免后续分析 `nativeads_als_every_log` 时混淆 `category_id`、`cmatch`、落地页 URL 和拼接键。

## 变更清单

- `commercial-sql-writer` skill 版本升级到 `0.1.1`。
- `SKILL.md` 增加“落地页性能、落地页抵达率”触发词和路由提示。
- `references/table-guide.md` 新增 `fc_nad.nativeads_als_every_log`，沉淀 `category_id = '1029'` 下常用 `f*` / `ef*` 字段映射。
- `references/scenario-router.md` 新增“落地页性能 / 抵达率”场景。
- `references/checklist.md` 增加抵达率 SQL 自查项。
- manifest 版本升级到 `0.19.14`，关键词补充 `landing-page`、`arrival-rate`。
- README 的 skill 能力描述补充落地页性能/抵达率。

## 架构决策

- 保持 `SKILL.md` 轻量，只放触发和 reference 路由；详细字段表放入 `references/table-guide.md`，符合 progressive disclosure。
- 抵达率相关 SQL 不新增脚本，原因是当前主要是字段映射和口径检查，直接沉淀 reference 更合适。
- 把 `f7=cmatch`、`f2=lp_real_url`、`f8+f6=search_id+idea_id` 写入 checklist，降低历史 SQL 检查时的误判概率。

## 排除项及原因

- 未新增单独落地页性能 skill：该能力属于商业广告 SQL 写作的子场景，拆成新 skill 会增加触发和维护成本。
- 未调整 DataPilot 跑数能力：本次只补 SQL 写作/检查口径，不涉及提交查询或结果回收流程。
