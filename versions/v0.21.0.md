# v0.21.0 - Comate 图片生成与 SVG 自审优化

## 目标

把本地 Comate 图片生成接口封装沉淀为通用 iPlugin skill，支持通过 Comate 兼容 API 生成图片、按语义保存输出文件，并在 API key 缺失或过期时走结构化询问。

同时针对 SVG 技术图反馈中常见的“上面很挤、下面很空、文字堆在一起”问题，补强布局预算和渲染自审规则。

## 架构决策

- skill 名称使用 `comate-image`，比 `comate-image-api` 更短，并能覆盖“用 Comate 出图”的自然表达。
- 将客户端脚本内置在 skill 中，而不是依赖外部 `/Users/.../comate-image-api` 路径，保证插件安装后仍可独立使用。
- `SKILL.md` 保留触发、流程、命名和密钥处理规则；接口细节放入 `references/`，符合 progressive disclosure。
- 脚本不接收 `--api-key` 参数，避免把密钥写入命令历史；只从环境变量或本地 key 文件读取。
- 语义命名由 agent 优先判断并传入 `--stem`；脚本只提供兜底 slug、扩展名补全和重名避让。
- SVG 布局修复选择强化现有 `svg-tech-diagram` 的预算与自审规则，不新增脚本；该问题依赖生成者在写 SVG 前做坐标预算、渲染后读图复核，规则比脚本后验检测更直接。

## 排除项及原因

- 不实现图片编辑、多图批量编排或后处理：本次目标是稳定封装已实测的三条生成链路。
- 不自动保存或刷新 API key：密钥属于用户私密信息，skill 只定义缺失/过期时的结构化询问流程。
- 不新增 slash command：该能力适合由自然语言触发 skill，避免重复维护 command 编排。
