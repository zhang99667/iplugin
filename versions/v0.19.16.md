# v0.19.16 - 补齐筛选字段 pageField 层级属性

## 目标

修复 `nad-acx-pivot-table` 在生成带 `filter_fields` 的原生 Excel 数据透视表时，Mac Excel 仍可能提示“发现部分内容有问题”的兼容性问题。

## 变更清单

- `skills/nad-acx-pivot-table/scripts/pivot_tool/pivot_table.py`
  - 将筛选字段生成的 `<pageField fld="..."/>` 改为 `<pageField fld="..." hier="-1"/>`。
- `skills/nad-acx-pivot-table/scripts/pivot_tool/ooxml_guard.py`
  - 新增零外部依赖的 PivotTable OOXML 兼容性闸门。
  - 检查 `refreshOnLoad`、多数据字段 `colFields/-2` 与 `colItems`、筛选字段 `pageFields hier="-1"`、枚举字段 `items` 覆盖、字符串枚举大小写重复和计算字段属性顺序。
- `skills/nad-acx-pivot-table/scripts/pivot_tool/packager.py`
  - 生成 xlsx 后自动调用 `assert_valid_pivot_xlsx()`，让结构问题在交付前失败。
- `skills/nad-acx-pivot-table/references/ooxml_pitfalls.md`
  - 记录真实 Excel 生成的页面筛选字段会带 `hier="-1"`。
  - 明确 `axisPage`、`pageFields` 和 `hier="-1"` 需要成套出现。
- `skills/nad-acx-pivot-table/references/config_schema.md`
  - 补充 `filter_fields` 会生成带 `hier="-1"` 的 `pageFields`。
- `skills/nad-acx-pivot-table/SKILL.md`
  - skill 版本升级到 `0.1.3`。
- `.claude-plugin/plugin.json` / `.codex-plugin/plugin.json`
  - 插件版本升级到 `0.19.16`。
- `CHANGELOG.md`
  - 新增 `0.19.16` 变更记录。

## 架构决策

- 保留原生 PivotTable OOXML 输出，不降级为普通汇总表。
- 继续支持 `filter_fields`，但按真实 Excel 生成结构补齐 `hier="-1"`，避免只生成结构容器但缺少层级属性。
- 增加生成后闸门，而不是只靠人工检查或 openpyxl；openpyxl 能读不代表 Excel 不会修复 PivotTable。
- 本次不改变预设字段、命名规则或数据透视布局。

## 排除项及原因

- 不把桌面交付文件改回预置筛选字段版本：用户当前需要的是能立即打开的交付文件，已用无预置筛选字段版本覆盖；`event_day` 仍保留在字段列表中，可在 Excel 内手动拖拽筛选。
- 不引入外部依赖或 Excel 自动化生成：当前工具要求零外部依赖，闸门同样只使用 Python 标准库解析 xlsx/OOXML。
