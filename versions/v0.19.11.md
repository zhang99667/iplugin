# v0.19.11 - HTML 报告 diff viewer 稳定性闸门

## 目标

修复 `html-report` 在展示真实 unified diff 时样式不稳定的问题。标准输出应保持脚本生成的 `.diff-card.diff-viewer` 结构，包含 old/new 行号、hunk header、红绿整行背景和左侧变更轨道，避免退化成普通 diff 文本块。

## 变更清单

- `skills/html-report/SKILL.md`
  - skill 版本升级到 `0.3.5`。
  - 明确真实 unified diff 必须原样嵌入 `highlight_code.py --lang diff --diff-view` 输出片段。
  - 禁止把真实 diff 降级成普通 `<pre>`、`language-diff` 或 `language-text` 代码块。
- `skills/html-report/references/content-rules.md`
  - 写作规范和完成前检查补充 diff viewer 结构稳定性要求。
- `skills/html-report/references/visual-rules.md`
  - 强调 `.diff-card.diff-viewer` 片段不能重包、拆散行号列或手写替代结构。
- `skills/html-report/references/css-template.md`
  - 明确最终 HTML 必须保留完整 diff viewer CSS，尤其是 old/new 行号列、代码列、增删行和红绿左侧轨道样式。
- `skills/html-report/scripts/check_html_report.py`
  - 拒绝包含 raw unified diff 的普通 `.code-wrap`。
  - 拒绝 `.diff-card.diff-viewer` 缺失 header、scroll、table、gutter、old/new 行号列、hunk 或增删行。
  - 检查 diff viewer 必需 CSS 片段，避免选择器缺失导致样式漂移。
- `.claude-plugin/plugin.json` / `.codex-plugin/plugin.json`
  - 插件版本升级到 `0.19.11`。
- `CHANGELOG.md`
  - 新增 `0.19.11` 变更记录。

## 架构决策

- 不改 `highlight_code.py` 的核心输出。脚本已有稳定的表格型 diff viewer，问题主要在生成时可能绕过或拆散该结构。
- 优先增强校验脚本。相比继续追加自然语言规则，确定性校验能在报告生成阶段直接拦截样式回退。
- 保持零依赖。新增检查只使用标准库正则和 HTMLParser，继续符合插件脚本可直接运行的约束。

## 排除项及原因

- 不引入截图级视觉回归测试：当前插件的交付检查以静态 HTML 结构为主，先用结构和 CSS 闸门覆盖高频漂移。
- 不增加新的 diff 样式体系：继续沿用现有 `.diff-card.diff-viewer`，避免标准样式继续分叉。
