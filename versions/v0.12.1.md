# v0.12.1

## 目标

增强 `mgit` skill 对百度 EasyBox/xbuild 多仓源码模式配置的处理能力。用户多仓改动上开发分支时，模型应能判断需要编辑 `overlay`；合入 master 前，模型应能判断 overlay 不能带上，并迁移或保留到个人 `local`。

## 变更清单

- `mgit` skill 升级到 `0.1.4`，触发边界加入 EasyBox modules、`overlay/local`、`syncSource`、源码模式、开发分支上车和 master 合入。
- 新增 `skills/mgit/references/easybox-overlay-local.md`，沉淀 EasyBox 上车配置流程。
- 增加仓库、EasyBox 模块路径、`xbuild/modules/default` 基础配置文件和 overlay/local 目标文件的映射规则。
- `command-guide.md` 与 `config-troubleshooting.md` 接入 EasyBox overlay/local reference。
- README 和 manifest 版本升级到 `0.12.1`，manifest 增加 EasyBox/xbuild 相关关键词。

## 架构决策

- 不把具体业务工程绝对路径写进 skill；规则只依赖相对目录 `xbuild/modules` 和 MGIT 只读诊断。
- 不根据仓库名直接猜 EasyBox 文件名；必须从 `xbuild/modules/default|overlay|local` 中查出映射证据。
- 不让 `syncSource` 直接驱动 `mgit sync`、`pull`、`clean` 等命令。它只用于构建源码模式配置，实际仓库状态仍由 MGIT/Git 确认。

## 排除项及原因

- 不新增解析脚本：当前先用 `rg` 和人工校验规则覆盖，避免引入未验证的 Gradle DSL 解析器。
- 不修改业务工程 EasyBox 文件：本次只更新 iPlugin skill 说明，不改变具体业务工程下的配置。
