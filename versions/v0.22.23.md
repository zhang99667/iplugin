# v0.22.23 - HTML Report Diff 变更指示条细化

## 目标

收窄 Diff Viewer 最左侧红绿状态条，降低大段连续增删行形成的厚重色块感，同时保持 `+/-` 符号和行号稳定对齐。

## 变更清单

- 新增、删除和上下文行的左侧轨道从 5px 统一调整为 2px。
- `+/-` gutter 总宽继续保持 25px，不压缩符号的阅读空间。
- 校验器要求红、绿和透明上下文轨道都使用 2px，防止不同类型行之间发生横向跳动。
- 组件回归覆盖正式样式和 5px 回退失败分支，并重建标准 Component Gallery。
- `html-report` skill 从 `0.7.2` 升级到 `0.7.3`，插件从 `0.22.22` 升级到 `0.22.23`。

## 架构决策

- 只调整状态色条宽度，不修改 gutter、old/new 行号列或 diff 生成器结构。
- 上下文行继续保留同宽透明边框，它不显示颜色，但负责维持所有行的列起点一致。
- 使用真实 Review 文档做只读浏览器验证，正式组件 CSS 注入后红绿条计算宽度从 5px 变为 2px，gutter 计算宽度仍为 25px。

## 排除项及原因

- 不把状态条缩到 1px：高分屏和浅色背景下辨识度不足，连续增删段落也不容易快速扫描。
- 不同步缩窄整个 gutter：`+/-` 是独立的变更语义，仍需要稳定的点击和阅读空间。
- 不修改用于验证的既有 Review HTML：测试通过浏览器临时注入正式组件 CSS 完成，避免污染交付文档。
