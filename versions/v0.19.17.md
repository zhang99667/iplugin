# v0.19.17 - HTML 报告媒体证据支持

## 目标

为 `html-report` 增加图片和视频证据展示能力，让报告可以按需嵌入截图、录屏预览、关键帧截图和原始媒体文件链接，同时保持默认报告结构轻量，不把媒体证据变成所有报告的强制要求。

## 架构决策

- 媒体证据采用可选增强，而不是报告基础模板的一部分。HTML 报告仍优先用文字、表格、代码 diff 和内联 SVG 表达结构化结论。
- 保持 CSS/JS 单文件约束，但允许图片和视频作为证据资源通过相对路径引用。媒体文件体积通常较大，不适合强制内嵌进 HTML。
- 校验脚本区分硬错误和建议项：断链、缺少图片 `alt`、视频缺少 `controls`、缺少响应式保护会失败；标题、说明、case、证据结论等证据卡完整性先输出 warning，避免把一次性截图或简单预览变成过重模板。

## 排除项及原因

- 不强制每份报告包含媒体：大多数技术报告、代码评审和方案文档不需要截图或录屏。
- 不强制每个媒体元素都必须写完整四段证据说明：简单截图或临时预览可能只需要 `alt` 和上下文说明。
- 不支持视频 base64 推荐路径：MP4 体积大，内嵌会显著膨胀 HTML，默认通过相对路径和原文件链接交付。
- 不引入媒体压缩或转码脚本：本次只做 HTML 展示和校验支持，媒体生产流程留给调用方或后续专门工具。
