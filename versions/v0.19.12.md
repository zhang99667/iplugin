# v0.19.12 - HTML 报告 diff 行号列自适应宽度

## 目标

优化 `html-report` 的 diff viewer 左侧指示区。上一版稳定了 `.diff-card.diff-viewer` 结构，但 old/new 行号列固定 54px，配合 `+/-` 轨道后在窄屏或截图中显得过宽，容易挤占代码内容。

## 变更清单

- `skills/html-report/references/css-template.md`
  - `+/-` 轨道调整为 25px。
  - old/new 行号列改为 `width: 1%; min-width: 40px; white-space: nowrap`。
  - diff 表格 `min-width` 改为 `100%`，避免短 diff 被固定 760px 宽度强制撑开。
- `skills/html-report/scripts/check_html_report.py`
  - 增加 `.diff-viewer .diff-gutter` 样式检查。
  - 增加 `width: 1%`、`min-width: 40px`、`min-width: 25px` 和 `white-space: nowrap` 检查，避免行号列回退成固定宽列。
- `skills/html-report/references/visual-rules.md`
  - 明确 old/new 行号列按内容自适应，`+/-` 轨道保持紧凑。
- `skills/html-report/SKILL.md`
  - skill 版本升级到 `0.3.6`。
- `.claude-plugin/plugin.json` / `.codex-plugin/plugin.json`
  - 插件版本升级到 `0.19.12`。
- `CHANGELOG.md`
  - 新增 `0.19.12` 变更记录。

## 架构决策

- 采用“自适应 + 最小宽度”而不是固定 `25 + 40 + 40`。常见 2-4 位行号保持紧凑，5 位以上行号可自然撑开，不需要生成器预估最大行号位数。
- 保留 old/new 双行号列。它们对代码评审和 patch 定位有价值，只压缩列宽，不合并语义。
- 不调整 `highlight_code.py` 输出结构。列宽属于 CSS 表达层，不需要改变脚本生成的 HTML。

## 排除项及原因

- 不把行号隐藏到 hover 或移动端折叠：报告常用于截图和离线审阅，行号应始终可见。
- 不只改成固定 40px：固定列在大行号文件中仍可能截断或抖动，自适应更稳。
