## 架构决策

**code-reading 不拆分**：190 行全是执行时必须遵守的工作流步骤，不是查阅型参考内容。Progressive Disclosure 的核心是"不需要时不加载"，code-reading 的内容每次都需要，拆分无收益。

**Telemetry hook 路径**：脚本放在仓库 `hooks/` 目录（CLAUDE.md 约定位置），hook 注册写入用户级 `~/.claude/settings.json`，两者解耦。安装说明写在脚本 docstring 里。

**validate 路径检测仅扫主文件**：`references/` 下的示例文档（如 html-report 的 CSS 模板）包含合法的示例路径，不应误报。
