# v0.19.3 - HTML 报告批注发布入口优化

## 目标

优化 `html-report` 离线批注审核模式的发布路径，让“没有批注、直接导出发布版”的主流程更明显。

## 变更清单

- `skills/html-report/scripts/inject_annotation_mode.py`
  - 0 条批注时，右上角入口从 `批注 0` 改为明确的 `导出发布版`。
  - 0 条批注时点击右上角入口直接导出发布版 HTML。
  - 右侧栏将 `导出发布版` 提升为首个全宽主按钮，Markdown/JSON 导出降为辅助操作。
  - 修正确认框语义：取消即取消导出，不再下载 `_public.html`；确认后优先保存/覆盖当前文件名。
  - 发布模式下强制隐藏计数徽标，避免 `导出发布版` 按钮右侧残留蓝色圆点。
- `skills/html-report/scripts/check_html_report.py`
  - 新增发布入口结构检查，防止后续回退为不明显的 `批注 0` 或弱化发布按钮。
- `skills/html-report/references/annotation-mode.md`
  - 补充 0 批注发布入口和右侧栏主按钮契约。

## 架构决策

- 保留单文件、离线和无后端设计，只调整注入脚本生成的 UI 层级。
- `导出发布版` 仍复用原有 `exportPublicHtml()`，避免新增第二套发布逻辑。
- 有批注时右上角继续显示 `批注 N`，因为此时用户更可能需要打开侧栏处理问题包。
- 取消导出必须是无副作用操作；浏览器不支持直接覆盖时，只在用户确认导出后下载当前文件名作为兜底。

## 排除项及原因

- 不新增“导出为”二级菜单：当前只有发布版、Markdown、JSON 三类导出，直接按钮比菜单更少一步。
- 不隐藏右上角入口：0 批注时它承担发布主入口，隐藏会让用户找不到发布动作。
