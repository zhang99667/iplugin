# v0.22.21 - HTML Report 组件 Gallery

## 目标

为 html-report 建立一个可直接查看、可确定性重建的组件标准样本，集中暴露组件组合后的结构问题，同时不引入浏览器视觉回归和普通报告生成耗时。

## 变更清单

- 新增 `assets/component-gallery/source.html`，覆盖默认、长内容、空状态和交互状态。
- 新增 `scripts/build_component_gallery.py`，使用正式代码高亮、Diff、Review Workspace、组件装配和评论注入入口生成单文件 Gallery。
- Gallery 覆盖注册表中的全部 13 个组件，并额外注入不属于普通组件注册表的评论复合模块。
- 新增 `test_component_gallery.py`，检查已提交 Gallery 未过期、组件声明完整、评论模式存在且最终 HTML 通过校验。
- 组件维护门禁新增 Gallery 更新步骤。
- `html-report` skill 从 `0.7.0` 升级到 `0.7.1`，插件从 `0.22.20` 升级到 `0.22.21`。

## 架构决策

- Gallery 是维护资产，不是报告模板；普通任务不会读取或构建它。
- 代码块、Diff 和 Review Workspace 不手写 DOM，统一调用正式生成器，防止示例和生产组件分叉。
- Gallery 输出提交到仓库，维护者无需启动服务即可直接打开；构建脚本的 `--check` 用逐字比较阻止生成产物过期。
- 评论模式继续作为生成后的复合模块，不为了 Gallery 进入普通页面组件注册表。
- Gallery 只提供确定性结构和交互样本，不承担浏览器截图或像素回归。

## 排除项及原因

- 不加入 Playwright、截图 diff 或多视口自动测试：用户明确暂缓浏览器级视觉回归。
- 不为 Gallery 新增独立 skill 或 command：它没有用户侧独立意图，只服务 html-report 维护。
- 不把 Gallery 接入普通报告生成步骤：避免增加日常上下文、I/O 和校验耗时。
