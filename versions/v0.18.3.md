# v0.18.3 — README 顶层目录结构修复

## 目标

修复 README 目录树仍然没有准确表达当前仓库结构的问题，避免把 skill 清单重复维护在目录树和 Skills 表两处。

## 变更清单

- README 的目录树改为“仓库顶层目录结构”。
- 补充 `tools/` 顶层目录，并列出当前跟踪的两个工具子项目。
- `skills/` 在目录树中只保留 `<name>/` 模板说明，不再手写展开所有 skill。
- `scripts/validate-plugin.py` 将 `tools/` 纳入 README 目录树必备顶层路径。
- 插件版本升级到 `0.18.3`。

## 架构决策

- README 顶层树只描述 Git 跟踪的顶层结构和关键文件，不列出 `.git/`、`.claude/`、`.obsidian/`、`.DS_Store` 或本地空目录。
- skill 的完整清单继续由 README 的 Skills 表和 `scripts/validate-plugin.py` 校验，不在目录树中重复维护。
- `tools/` 是仓库内跟踪内容，但不自动进入插件 manifest；README 只在目录结构中说明其边界。

## 排除项及原因

- 不列出空的 `docs/` 目录：当前没有被 Git 跟踪的内容，写入 README 会制造新的漂移。
- 不恢复逐个 skill 的目录树展开：这会和 Skills 表形成重复真源，后续新增或删除 skill 时更容易再次不一致。
