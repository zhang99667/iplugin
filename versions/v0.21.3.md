# v0.21.3 - 版本递增规则修正

## 目标

修正维护指南里的版本递增规则：第二位版本号只用于新增 skill，方便通过插件版本粗略判断新增 skill 数；已有 skill 的改名、修复、指令优化、文档和 manifest 调整都走 patch。

## 变更清单

- `AGENTS.md` / `CLAUDE.md`
  - 将 `Minor（新增/改名 skill）` 改为 `Minor（新增 skill）`。
  - 明确非新增变更，包括改名 skill、修复、文档、manifest、hooks 和 scripts 调整，都升级第三位版本号。
- `.claude-plugin/plugin.json` / `.codex-plugin/plugin.json`
  - 插件版本升级到 `0.21.3`。
- `CHANGELOG.md`
  - 新增 `0.21.3` 版本记录。

## 架构决策

- 保持 `AGENTS.md` 与 `CLAUDE.md` 同步，因为二者是同源维护指南。
- 把版本语义写在维护指南中，而不是只修正某次版本记录，避免后续改名或修复继续误升 minor。

## 排除项及原因

- 不修改历史版本文档中的旧决策描述；历史文档记录当时的判断，本次只修正当前生效的维护规则。
