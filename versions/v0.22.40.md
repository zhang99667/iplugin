# v0.22.40 - HTML Report 批注意图分流

## 目标

让“复制批注给 Agent”的交接提示区分问题咨询与 HTML 修改：问题直接回答，只有明确修改要求才改 HTML

## 变更清单

- 交接包提示 Agent 先判断用户意图
- 问题或解释请求直接回答，不修改 HTML
- 明确要求修改批注、报告或 HTML 时，才修改同一份 HTML 并写入 `AgentReviewReceipt`
- 用户明确指定“回答”或“修改”时，以该指令为准
- 同步更新批注模式帮助文案、参考文档、版本和测试

## 架构决策

- 只调整交接提示词和界面说明，不改变 `AgentQuestionPack` 数据结构、批注定位和回执校验
- “修改”路径继续要求写入回执，保持现有落盘证明

## 排除项及原因

- 不在 HTML 端自动解析自然语言意图，避免把 Agent 的上下文判断硬编码进离线报告
- 不改变普通问题批注的展示、复制和导出流程
