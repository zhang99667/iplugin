# v0.21.4 - Android mock 验收证据规则收紧

## 目标

补齐 Android mock 验收报告的交付约束，避免后续自测时覆盖历史报告，或只在总表/附录里引用证据而没有在每个 case 下直接呈现可复核材料。

## 变更清单

- `skills/android-mock/SKILL.md`
  - skill 版本升级到 `0.1.1`。
  - 新增“验收报告必须新增或版本化输出”的硬约束，目标目录已有报告时不得覆盖旧报告，除非用户明确要求替换。
  - 新增逐 case 证据直贴要求：每个 case 的结论下方必须直接放截图预览、录屏预览或 mock/logcat/dumpsys 超链接。
  - 调整报告结构建议，将“证据附录”改为“逐 case 证据块”，并明确附录不能替代 case 下证据。
- `.claude-plugin/plugin.json` / `.codex-plugin/plugin.json`
  - 插件版本升级到 `0.21.4`。
- `CHANGELOG.md`
  - 新增 `0.21.4` 版本记录。

## 架构决策

- 把强约束放在 `android-mock` skill，而不是 `html-report` skill。`html-report` 的图片/视频能力仍然保持通用可选；Android mock 验收属于强证据场景，应由调用方 skill 强制逐 case 证据呈现。
- 仅升级 patch 版本，因为本次是已有 skill 的验收规则优化，没有新增 skill 或新增独立能力入口。

## 排除项及原因

- 不要求所有 HTML 报告都必须贴媒体证据；普通技术报告、代码评审报告不一定需要图片或视频。
- 不把完整代码或 diff 放进 mock 验收报告；报告只要求方案、结论和证据可追溯。
