# v0.8.1 结构化询问命令入口收敛

## 目标

收敛 ask-user-question 的 slash command 入口，只保留一个用户可见命令，避免命令列表里出现重复项。

## 变更清单

- 删除 `/askuserquestion` 命令文件。
- 保留 `/ask-user-question` 作为唯一命令入口，并承载完整执行说明。
- `ask-user-question` skill 版本从 `0.1.0` 升级到 `0.1.1`。
- 插件版本从 `0.8.0` 升级到 `0.8.1`。
- 更新 README、CHANGELOG 和 manifest 关键词。

## 架构决策

- 使用与 skill 名称一致的 `/ask-user-question` 作为规范入口。
- 不保留 alias，减少用户在命令列表里的选择成本。
- 开发准则中已经引用 `/ask-user-question`，因此命令入口与准则保持一致。

## 排除项

- 不改变结构化询问行为本身。
- 不调整已存在的其它 skill 或未提交工作区内容。
