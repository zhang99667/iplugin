# v0.22.13 - HTML 报告组件稳定性

## 目标

修复普通表格边框和多文件 Diff 分组仍依赖模型临场装配的问题，把高频视觉组件下沉为确定性生成与强校验能力。

## 变更清单

- 在必选 `base.css` 中加入 `.table-wrap` 普通表格组件，统一完整 1px 网格线、表头、隔行底色、窄屏滚动和打印边框。
- 将可排序表格的 wrapper 名称收敛为 `.table-wrap`，排序组件只负责增强交互，不再维护另一套基础表格外观。
- `highlight_code.py --lang diff --diff-view` 自动按 `diff --git` 或连续 `---` / `+++` 文件头拆分多文件 patch，并在每张卡片标题中展示 `.diff-file`。
- `check_html_report.py` 拒绝裸普通表格、只有底边框的单元格、缺文件标题的 Diff viewer，以及一张卡片混装多个文件的输出。
- 增加表格和 Diff 的正向、反向 7 项单元测试，并补充组件稳定性 eval。
- 更新 `html-report` 使用契约、CSS 装配规则、视觉规则、README 和评论模式基础 fixture。
- `html-report` skill 升级到 `0.5.3`，两个插件 manifest 同步升级到 `0.22.13`。

## 架构决策

- 不把表格、Diff、目录等页面组件拆成独立 skill。它们没有独立用户触发语义，拆分会增加 skill 选择、上下文加载和版本协同成本。
- 保留 `html-report` 作为内容编排入口；稳定性要求通过 CSS 组件、生成脚本和校验器下沉到低自由度实现。
- 普通表格是高频基础能力，直接放入必选 `base.css`；Diff 继续归属按需加载的 `code-diff.css` 和 `highlight_code.py`。
- 校验器只检查可确定的结构和 CSS 契约，不评价表格内容质量或报告叙事结构。

## 排除项及原因

- 不新增通用表格生成脚本。语义化 `<table>` 本身稳定，当前缺口是统一样式和门禁，额外生成器收益不足。
- 不修改 Review Workspace、评论模式或媒体组件，它们已有独立构建/注入脚本，本次反馈未指向这些链路。
- 不修改现有未跟踪 HTML 报告；本版本只提升后续生成和校验能力。
