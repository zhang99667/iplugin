# v0.18.2 — 触发文案一致性修复

## 目标

统一当前文档和 skill 的 slash 触发口径，避免 README、manifest 默认示例和 SKILL.md 对 command 层状态的描述互相矛盾。

## 变更清单

- `html-report` 当前触发命令统一为 `/html-report`。
- `best-of-web` 移除“命令文件明确要求”的旧描述，改为用户显式 `/best-of-web` 或上游规则指定时触发。
- Codex `defaultPrompt` 中的联网精选示例改为显式 `/best-of-web ...`。
- `AGENTS.md` 与 `CLAUDE.md` 将 `commands/` 描述为可选目录，强调不要和同名 skill 重复注册。
- `scripts/validate-plugin.py` 新增当前触发文案一致性检查，覆盖 `/html-report`、`best-of-web` defaultPrompt 和已删除 command 文件文案。
- 插件版本升级到 `0.18.2`。

## 架构决策

- 只修改当前有效文档、skill 和 manifest，不回写历史版本记录里的旧命令事实。
- 不恢复 `commands/` 目录。当前 `/html-report`、`/best-of-web`、`/ask-user-question` 都由 skill 触发语义承载。
- 新闸门只覆盖这次暴露出的具体一致性风险，避免把校验脚本扩展成难维护的自然语言 lint。

## 排除项及原因

- 不删除 `commands/` 维护说明：未来仍可能存在非重复 command 编排入口，因此保留为可选目录规则。
- 不把旧 `/htmlreport` 作为 alias 写回当前 skill：当前 README 已选择 `/html-report`，继续保留旧别名会让触发口径再次分叉。
