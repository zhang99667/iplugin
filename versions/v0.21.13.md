# v0.21.13 - 代码编写中文注释规则

## 目标

把代码编写或修改时的注释要求固化到 iPlugin 维护指南中，要求后续在本插件仓库内改代码时写清楚中文注释，不只覆盖方法级说明，也覆盖方法内部关键逻辑。

## 变更清单

- `AGENTS.md` / `CLAUDE.md`
  - 新增“代码编写注释规则”小节。
  - 明确代码编写或修改时，方法、类、脚本入口等对外结构需要中文注释。
  - 明确方法内部关键逻辑、分支条件、边界处理和非显而易见的实现意图也需要中文注释。
  - 要求注释解释“为什么这样做”和“这段逻辑保护什么约束”，避免只复述代码。
- `.claude-plugin/plugin.json` / `.codex-plugin/plugin.json`
  - 插件版本升级到 `0.21.13`。
- `CHANGELOG.md`
  - 新增 `0.21.13` 版本记录。

## 架构决策

- 这条规则是仓库维护行为约束，不是新增可复用 skill，因此写入 `AGENTS.md` 和 `CLAUDE.md`，并按 patch 版本发布。
- 保持两份维护指南同步，因为它们分别服务 Codex 和 Claude Code，但表达同一套仓库约束。
- 规则强调解释意图和约束，避免注释退化为对代码字面行为的重复描述。

## 排除项及原因

- 不新增独立 skill。注释规则属于本仓库通用维护准则，不需要用户额外触发。
- 不改 README。README 面向插件能力介绍，这次不新增用户可见能力。
- 不修改已有代码补注释。本次只新增未来代码编写/修改时应遵守的规则。
