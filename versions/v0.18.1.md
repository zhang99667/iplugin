# v0.18.1 — README 目录结构与闸门对齐

## 目标

修复 README 目录结构与当前插件核心结构不一致的问题，并把这类文档漂移纳入提交前校验。

## 变更清单

- README 的目录结构改为“插件核心目录结构”。
- 从 README 目录树中移除已删除的 `commands/` 顶层目录。
- 在 Commands 小节说明当前没有独立 `commands/*.md` 入口，slash command 触发语义由同名 skill 承载。
- `scripts/validate-plugin.py` 新增 README 目录树检查，要求核心顶层路径被列出，且列出的顶层路径必须存在。
- 插件版本升级到 `0.18.1`。

## 架构决策

- 不恢复空 `commands/` 目录。Git 不跟踪空目录，恢复目录需要额外 `.gitkeep`，但当前并没有独立 command 文件需要承载。
- 不把 `tools/` 重新写回 README 插件核心目录。`tools/` 是仓库内独立工具子项目，不属于插件 manifest 直接暴露的结构。
- 闸门只校验 README 目录树里的顶层核心路径，避免把文档树变成对仓库内所有实验性或独立子项目的完整快照。

## 排除项及原因

- 不新增 `commands/.gitkeep`：当前 slash command 已由 skill description 承载，保留空目录会暗示仍存在 command 层入口。
- 不扩大校验到完整递归文件树：README 目录树是维护视图，不应该被迫列出所有内部文件、缓存文件或独立工具子项目。
