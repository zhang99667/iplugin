# v0.22.30 - HTML Report 问题与评论双入口

## 目标

让用户在创建批注时直接表达“需要 Agent 回答的问题”或“对报告内容的评论”，避免单一“添加批注”入口丢失处理意图。

## 变更清单

- 选区气泡恢复 `问题` 和 `评论` 两个直接入口。
- 右键菜单在选中内容、本段和本节三个作用范围下分别提供问题和评论。
- 输入浮层根据类型切换图标、标题和占位提示；编辑已有条目时保留原类型。
- 批注卡片显示问题或评论徽标，评论使用独立配色。
- Markdown 剪贴板包、单条复制和内嵌 `AgentQuestionPack` 保留规范化后的类型。
- 旧 `提问` 映射为 `问题`，旧 `注释 / 批注` 映射为 `评论`。
- 同步更新校验器、运行时测试、组件测试、Gallery、eval 和文档契约。
- `html-report` skill 从 `0.7.8` 升级到 `0.7.9`，插件从 `0.22.29` 升级到 `0.22.30`。

## 架构决策

- `批注` 继续作为工作区、轮次状态和 Agent 交接的总称，单条内容只在需要表达处理意图时区分问题和评论。
- 类型在创建入口直接确定，不增加类型下拉或二次确认。
- 侧栏通过卡片徽标展示类型，但不恢复类型筛选，避免重新增加扫描和操作复杂度。
- 保持 `AgentQuestionPack 0.3.0` schema 不变，只继续使用既有 `kind` 字段承载规范化类型。

## 排除项及原因

- 不恢复旧的“全部 / 提问 / 注释”筛选栏；用户本轮只要求区分新增类型。
- 不修改上一版确定的保存/发布并排布局、清空直达和紧凑字号。
- 不新增回复线程、优先级或更多类型；先保持问题和评论两个稳定选择。
