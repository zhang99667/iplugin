# v0.13.7

## 目标

精简 `html-report` skill 中重复和冲突的声明，让主 `SKILL.md` 只负责触发、路由和输出契约，细节继续通过 references 渐进披露。

## 变更清单

- `html-report` skill 升级到 `0.2.18`。
- 修正 `artifact-patterns.md` 的导航说明，明确当前覆盖技术方案、技术调研、问题排查/修复方案三个高频场景。
- 删除主 skill 中与 references 重复的可选依赖长段说明，保留“不静默安装依赖”的核心约束。
- 移除“CDN 图表库除外”的例外，统一要求最终 HTML 为单文件离线输出。
- 将“颜色即信息”调整为“颜色辅助信息”，与可访问性规则保持一致。
- README 与两个 manifest 版本升级到 `0.13.7`。

## 架构决策

- 不拆分 `css-template.md`：本次目标是消除重复和冲突表述，避免把范围扩大到模板文件重组。
- 不新增新的报告类型模板：现有三类模板已经覆盖当前高频场景，其他类型继续按通用规则处理。
- 保持 Pygments 为可选增强：默认仍使用 builtin 静态高亮，不联网、不安装依赖。

## 排除项及原因

- 不处理 hook 配置校验失败：该问题不属于 `html-report` 优化范围，避免混入无关改动。
- 不调整 plugin 描述和关键词：本次没有新增能力，只做已有能力的规则收敛。
