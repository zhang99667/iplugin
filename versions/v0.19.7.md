# v0.19.7 - SVG 技术图画布留白规则优化

## 目标

修复 `svg-tech-diagram` 容易把单行流程图套进固定大画布的问题。画布尺寸应跟随内容结构，单行图不应在下方留下大面积空白。

## 变更清单

- `skills/svg-tech-diagram/SKILL.md`
  - 将 skill 版本升级到 `0.1.1`。
  - 明确写 SVG 时使用按内容收缩的 `viewBox`。
- `skills/svg-tech-diagram/references/style-system.md`
  - 将推荐画布改为内容驱动：`1200x675` 只作为多层横图示例，单行流程优先使用较矮画布。
  - 要求背景 `<rect>` 尺寸与 `viewBox` 同步。
- `skills/svg-tech-diagram/references/svg-patterns.md`
  - 说明骨架中的 `1200x675` 不是固定尺寸，并给出单行流程收紧示例。
- `skills/svg-tech-diagram/references/review-checklist.md`
  - A 级检查增加“大面积空白”项。
  - 用户反馈映射增加“空白太多”的排查方向。
- `.claude-plugin/plugin.json` / `.codex-plugin/plugin.json`
  - 插件版本升级到 `0.19.7`。

## 架构决策

- 不新增脚本或自动裁剪工具；这类问题通常能通过生成 SVG 时正确设置 `viewBox` 解决。
- 保留 `1200x675` 作为复杂横图示例，但明确它不是所有图的默认最终尺寸。

## 排除项及原因

- 不强制固定单行高度：不同标题、节点高度和图注需求不同，固定高度容易裁切或再次产生不合适的比例。
- 不改渲染脚本：渲染脚本只负责 SVG 到 PNG，画布语义应由 SVG 源文件决定。
