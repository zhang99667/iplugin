# v0.19.7 - HTML 报告长文件路径块截断规则

## 目标

修复 `html-report` 在证据来源、表格或摘要卡片中直接展示超长文件路径时，容易撑破布局或形成难读换行的问题。即使文件路径没有行号，也应该保留语义后截断展示。

## 变更清单

- `skills/html-report/SKILL.md`
  - 将 skill 版本升级到 `0.3.4`。
- `skills/html-report/references/visual-rules.md`
  - 明确长文件路径不能直接作为普通 `<code>` 完整展示。
  - 要求无行号路径也使用 `.path` chip 或等价结构，以 `...` 省略中间目录。
  - 要求保留仓库/模块线索、完整文件名，以及必要的方法名或行号语义。
- `skills/html-report/references/content-rules.md`
  - 写作规范和完成前检查补充长文件路径块截断要求。
- `.claude-plugin/plugin.json` / `.codex-plugin/plugin.json`
  - 插件版本升级到 `0.19.7`。

## 架构决策

- 不新增脚本或复杂自动缩写算法；当前问题属于生成规则缺失，优先通过 skill 约束生成行为。
- 继续复用已有 `.path` / `.file-link` 视觉系统，避免为“无行号路径”新增另一套样式。

## 排除项及原因

- 不要求所有路径都缩短：短路径完整展示更直观，只有撑破卡片或换行难读时才省略中间目录。
- 不改变 `href` / `title` 契约：视觉缩短不能牺牲跳转或可追溯信息。
