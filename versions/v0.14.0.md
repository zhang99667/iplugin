# v0.14.0

## 目标

将外部个人 `obsidian` skill 迁入 iPlugin，使 Obsidian 笔记写作规范由插件统一维护，并可同时被 Claude Code 与 Codex 复用。

## 变更清单

- 新增 `skills/obsidian/SKILL.md`，内容来自 `/Users/markz/.agents/skills/obsidian/SKILL.md`。
- 为 `obsidian` 补齐插件规范要求的 `version`、`tags` 和 `user_invocable` frontmatter。
- README 增加 `obsidian` skill 的目录说明、能力表和触发示例。
- 两个 manifest 的插件版本升级到 `0.14.0`，描述和关键词加入 Obsidian 笔记写作能力。
- CHANGELOG 增加 `0.14.0` 版本记录。

## 架构决策

- 迁入插件后以 `skills/` 作为唯一真源，不再依赖外部 `~/.agents/skills/obsidian`。
- 保持该 skill 为单文件：当前规则量较小，暂不拆分 `references/`。
- Vault 路径使用 `$HOME/Documents/Obsidian Vault/` 表达，保留个人工作流配置含义，同时避免在 skill 中硬编码绝对 home 路径。

## 排除项及原因

- 不新增 slash command：Obsidian 写作可由自然语言触发，不需要命令入口。
- 不调整写作规则本身：本次目标是迁移与插件索引更新，不混入格式策略变更。
