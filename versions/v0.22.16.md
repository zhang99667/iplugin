# v0.22.16 - 选区注释入口收敛

## 目标

参考 Codex 的选区操作，把高频气泡从类型选择器收敛为单一动作，减少用户在写内容前的判断成本。

## 变更清单

- 选中文本后的轻量气泡只显示一个 `注释` 按钮。
- 新建内容统一记录为 `注释`，输入、快捷提交和侧栏交接流程保持不变。
- 右键菜单继续提供提问和添加注释的细分入口，承载低频高级操作。
- 读取、编辑和导出时继续识别旧评论包中的 `批注` 类型。
- 校验器、仓库资产检查、eval 和真实注入回归同步加入单入口门禁。
- `html-report` skill 从 `0.6.1` 升级到 `0.6.2`，插件从 `0.22.15` 升级到 `0.22.16`。

## 架构决策

- 高频选区操作只暴露用户目标“添加注释”，不要求预先区分提问或修改建议。
- 不删除提问能力；右键菜单仍提供显式提问入口，已保存的 `提问` 类型也继续正常显示和编辑。
- 不迁移历史评论数据；运行时通过兼容判断同时识别 `注释` 与 `批注`。

## 排除项及原因

- 不增加新的组件或配置开关：这是现有批注复合模块的交互收敛。
- 不修改 AgentQuestionPack schema：`kind` 本来就是文本字段，继续承载兼容值即可。
