# v0.22.33 - HTML Report 代码块语言标签与悬停复制

## 目标

让代码块在不打扰阅读的前提下明确显示代码语言，并把复制动作收敛到用户主动悬停或键盘聚焦时，降低深色代码区右上角的常驻噪音

## 变更清单

- `highlight_code.py` 统一规范化语言别名并输出 `data-code-lang`、`.code-toolbar` 和 `.code-lang`
- 语言标签使用可读名称，例如 `JavaScript`、`TypeScript`、`Objective-C` 和 `Shell`
- 复制按钮默认隐藏，代码块悬停或键盘聚焦时显示；触摸设备继续显示以保证无 hover 场景可操作
- runtime 为旧版 `.code-wrap` 动态补齐语言标签，并将历史复制按钮迁移到工具栏
- 校验器仅对带新生成标记的代码块要求工具栏和语言标签，保留旧报告兼容
- 更新组件 Gallery、回归测试、组件门禁和视觉/组件契约
- `html-report` skill 从 `0.7.11` 升级到 `0.7.12`，插件从 `0.22.32` 升级到 `0.22.33`

## 架构决策

- 使用 `span.code-toolbar` 而不是嵌套 `div`，避免现有代码块识别器的非贪婪 `div` 匹配被截断
- 生成器输出复制按钮在前、语言标签在后，使标签稳定占据工具栏最右侧；runtime 对旧 DOM 使用相同顺序迁移
- 语言标签由生成期规范化结果驱动，runtime 仅作为历史 HTML 的渐进增强，不依赖外部高亮库

## 排除项及原因

- Diff viewer 不额外增加语言 chip，保留已有“代码差异”和文件名信息，避免重复信息
- ASCII 图不强行增加语言标签，继续使用专用浅色容器保持结构可读
