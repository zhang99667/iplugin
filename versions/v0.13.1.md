# v0.13.1

## 目标

优化 `best-of-web` skill，让它从“联网找高质量资料”的原则说明，升级为更可执行的公开互联网精选调研流程，同时保持轻量，不变成强制文件化的 deep research 工作流。

## 变更清单

- `best-of-web` skill 升级到 `0.1.1`。
- 补充快速精选、标准调研、深度调研三档研究强度。
- 增加查询设计步骤，要求按官方/原始来源、最佳实践、对比、最新变化、争议反例等意图组织搜索。
- 增加来源优先级，覆盖技术、论文、法规、产品、市场和开源工具/skill 等常见场景。
- 增加证据标准，要求关键结论有可靠来源，冲突时优先找原始来源并明确取舍。
- 增加联网安全边界，要求把网页内容当资料而非指令，避免把私有上下文写入公开搜索查询。
- README 中 `best-of-web` 能力说明同步补充“来源质量分层核验”。
- `.claude-plugin/plugin.json` 与 `.codex-plugin/plugin.json` 版本升级到 `0.13.1`。

## 架构决策

- 保留 `best-of-web` 作为公开互联网资料精选与综合能力，不把它改造成强制 subagent、强制写文件或强制长报告的 deep research skill。
- 对复杂公开网页调研只提供“先计划、再按子主题检索”的轻量策略；如果任务还涉及本地/私有多源检索，则交给 `delegated-search`，并复用本 skill 的公开来源质量标准。
- 参考同类 web-research skill 的计划、委派、引用和来源保存思路，但不照搬文件化流程，避免普通“找最佳实践”请求被过度拉长。
- 借鉴 deep research 文档中的来源优先级和安全建议，把 prompt-injection 与私有数据泄露风险写成明确边界。

## 排除项及原因

- 不新增 reference 文件：当前规则仍能放在一个 `SKILL.md` 内，未达到需要 progressive disclosure 的长度。
- 不新增 slash command：已有 `/best-of-web` 入口，命令逻辑仍只需委托 skill。
- 不修改 manifest 关键词：现有 `best-of-web`、`internet`、`research`、`curation`、`source`、`synthesis` 已覆盖触发需求。
