# v0.11.1

## 目标

优化 `html-report` skill，让它在参考优秀 HTML artifact / HTML report skill 后，能更稳定地判断什么时候值得生成 HTML，并按报告类型组织更像交付物的页面。

## 变更清单

- `skills/html-report/SKILL.md` 升级到 `0.2.10`，补充 `artifact-patterns.md` 的 progressive disclosure 路由。
- 新增 `skills/html-report/references/artifact-patterns.md`，先沉淀技术方案和技术调研两个高频页面结构模板。
- 更新 `references/content-rules.md`，加入 HTML 价值信号、首屏 TL;DR、证据来源区和生成后 Review/Improve 自查。
- 更新 `references/visual-rules.md`，补充响应式、打印友好、可访问性和语义 HTML 底线。
- 插件 manifest 版本升级到 `0.11.1`。

## 架构决策

- 不新增独立 HTML artifact builder skill；`html-report` 仍聚焦工程报告、技术文档和分析交付物。
- 不引入 React、Tailwind、构建器或外部依赖；保持单文件 HTML、内嵌 CSS/JS 的低摩擦交付方式。
- 将技术方案和技术调研模板放入 references，避免主 `SKILL.md` 过长，同时让生成时按需读取。

## 排除项

- 不改变 `/htmlreport` 的命令入口和触发方式。
- 不把普通总结、短结论或无需可视化的信息自动升级为 HTML。
- 不新增脚本校验浏览器渲染；当前先通过生成后自查规则提升质量。
- 不在本次覆盖代码评审、问题排查、状态报告等其他场景；这些模板等后续基于真实使用再补。
