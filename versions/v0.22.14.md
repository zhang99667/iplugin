# v0.22.14 - HTML Report 组件化重构

## 目标

保留一个对外 `html-report` skill，把表格、代码、Diff、IDE 跳转、媒体、灯箱、目录、Tabs、
排序和 Review Workspace 收敛为可组合的内部组件；用统一装配器和组件级门禁替代 Agent
临场复制 CSS/JS，降低报告生成的不稳定性。

## 变更清单

- 新增 `assets/components/registry.json`，记录组件类别、依赖、CSS/JS 和稳定检测标记。
- 新增 `scripts/assemble_report.py`，自动检测组件、拓扑展开依赖、去重并幂等内联资产。
- 将旧 `references/css/` 资产迁到 `assets/components/`；普通表格从 `base` 拆为 `table`，
  原 `code-diff` 拆为 `code-block` 和 `diff-viewer`。
- 将复制、TOC、Tabs 和排序脚本从文档示例迁入组件 runtime，并保留无 JS 可读回退。
- 新增 `file-location`：默认显示 `文件名:起始行-结束行`，同名时最多增加一级父目录；完整
  路径和行号保留在 `href` / `title`。
- 新增 `image-lightbox`：媒体证据图片以原图链接回退，支持原生 `<dialog>` 点击放大。
- Review Workspace standalone 预览接入统一装配器，静态和 runtime 路径展示使用同一契约。
- 扩展 `check_html_report.py` 和 `scripts/validate-plugin.py`，检查组件依赖、资产、runtime、
  Table、Diff、Tabs、排序、TOC、灯箱和 IDE 定位。
- 新增 `references/component-contracts.md`，重写装配流程，删除 reference 中重复 runtime。
- 新增 `docs/html-report-component-architecture.md` 作为较大架构改造留档。
- `html-report` skill 从 `0.5.3` 升级到 `0.6.0`，插件升级到 `0.22.14`。

## 架构决策

- UI 组件不拆成独立 skill；`html-report` 继续负责用户意图、内容编排和最终交付。
- `references/` 保存 Agent 按需读取的契约，`assets/` 保存实际输出资产，`scripts/` 负责低自由度
  构建和校验。
- 注册表是组件依赖和资产的单一真源；装配器与校验器共享它，避免两份依赖清单漂移。
- `annotation-mode` 保持生成后的独立注入模块，不进入普通页面组件注册表。
- 新报告必须走装配器；没有组件声明的历史 HTML 暂时保持校验兼容，不做批量迁移。
- 交互遵循渐进增强：Tabs、TOC、排序和灯箱在 JS 不可用时仍保留全部内容或原生链接。

## 版本决策

这是单个 skill 的内部生成架构大改，因此 `html-report` 使用较大的 `0.6.0` 升级。没有新增
skill，插件版本仍遵守 `0.<累计新增 skill 数>.<优化次数>`，第二位保持 `22`，第三位从 `13`
增加到 `14`；不升级第一位。

## 排除项及原因

- 不新增 Table、Diff、Lightbox 等独立 skill：它们没有独立用户触发语义。
- 不引入前端 framework、CDN、npm 构建链或浏览器端语法高亮：单文件离线约束保持不变。
- 不自动迁移历史 HTML：避免重写已交付报告和其中可能存在的评论数据。
- 不让组件系统规定报告章节：叙事结构仍由读者任务和内容材料决定。
