# v0.22.8

## 目标

修复 `nad-acx-pivot-table` 在存在页面筛选字段时生成损坏 xlsx 的问题，使文件可被 Microsoft Excel 无修复提示地打开并自动刷新原生透视表。

## 变更清单

- 按 `filter_fields` 数量为页面筛选区预留纵向行和 1 个间隔行，透视主体不再固定从 A1 开始。
- 有页面筛选字段时写入 `rowPageCount`、`colPageCount`，并使用经 Excel 验证的 `firstDataRow=1`。
- OOXML guard 校验页面区与主体不重叠、页面计数完整，以及 `location` 高度与 `firstDataRow + rowItems` 一致。
- 新增 0、1、2 个页面筛选字段的生成与 guard 回归测试。
- 更新 OOXML 踩坑文档，移除“只要存在 Values 列就固定 firstDataRow=2”的错误规则。

## 架构决策

- 保留无页面筛选字段时的既有布局，避免扩大本次兼容性修复的影响面。
- 继续使用空透视工作表加 `refreshOnLoad=1` 的现有方案；真实 Excel 已证明只修正 `location` 即可正确重建透视结果，因此本次不引入结果单元格预计算。
- 不把默认样式补全并入本次修复；完整替换样式不能消除原故障，样式不是已验证的根因。

## 排除项

- 不调整透视表业务指标、行列字段或筛选字段配置。
- 不改变 PivotCache 记录、计算字段公式和原始数据 sheet。
- 不尝试把 OOXML guard 扩展成通用 Excel 文件验证器；本次只固化已复现的页面布局不变量。
