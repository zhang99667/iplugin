# v0.22.22 - HTML Report Diff 行号区紧凑化

## 目标

缩减 Diff Viewer 左侧 old/new 行号区的无效空白，并移除两列之间容易被误认为额外内容边界的竖线，让代码区域获得更多可用宽度。

## 变更清单

- `diff-viewer/style.css` 将 old/new 行号列从 `min-width: 40px` 改为 `min-width: 0`，继续用 `width: 1%` 和不换行约束按当前 diff 的最长行号自然撑开。
- `.diff-old-num` 强制取消右边框；`.diff-new-num` 继续保留右边框，作为行号区与代码区的唯一边界。
- `check_html_report.py` 新增同规则声明校验，拒绝固定宽行号列和 old/new 内部竖线回退。
- 组件回归新增紧凑行号样式与失败分支测试，并重建标准 Component Gallery。
- `html-report` skill 从 `0.7.1` 升级到 `0.7.2`，插件从 `0.22.21` 升级到 `0.22.22`。

## 架构决策

- 保留 old/new 两个语义列及原有 HTML 结构，不合并行号，也不引入运行时 JavaScript 测量。
- 表格布局根据同一张 diff 内的最长行号统一列宽，因此不同位数行号仍能稳定对齐，同时常见两到四位行号不再承担固定 40px 宽度。
- 只对 `.diff-old-num` 的边框使用 `!important`，用于覆盖历史报告中 `.diff-num` 的强制边框；不扩大强制样式范围。
- 使用真实 Review 文档做只读浏览器验证：三位行号场景的 old/new 列从 `40px + 40px` 收缩到约 `35.5px + 36.0px`，内部边框从 `1px` 变为 `0`，代码区边界仍为 `1px`。

## 排除项及原因

- 不隐藏、合并或悬浮显示 old/new 行号：两列仍是代码评审定位补丁的重要信息。
- 不修改 diff 生成器：问题只属于组件 CSS 表达层，现有语义 DOM 正确。
- 不改写用于验证的既有 Review HTML：测试通过浏览器临时注入正式组件样式完成，避免污染交付文档。
