# v0.4.0

## 目标

新增 iCafe 需求交付材料归档能力，把需求卡片正文和技术详设统一整理到桌面“需求交付”目录，便于后续复盘、汇总和查找。

## 变更清单

- 新增 `icafe-delivery-archive` skill
- 支持从详设文件名、HTML title、正文卡片号或 iCafe 链接识别 `<space>-<sequence>`
- 支持调用 iCafe 客户端查询卡片详情并生成 `需求描述 · <space>-<sequence>.html`
- 支持复制用户提供的技术详设到目标目录并统一命名为 `技术详设 · <space>-<sequence>.<ext>`
- 更新插件描述、关键词和 changelog

## 架构决策

- 归档目录固定使用 `/Users/markz/Desktop/需求交付`，符合当前个人工作流。
- 需求描述输出 HTML，而不是 Markdown，以保留 iCafe 富文本、图片和链接。
- 技术详设默认复制，不移动原文件，避免破坏用户已有目录结构。
- iCafe 查询复用现有 `icafe-card-assistant` 的 Python 客户端，不在本插件内重复实现认证和 API 逻辑。

## 排除项

- 不自动生成项目复盘总结；复盘总结由 `project-summary` 处理。
- 不自动创建或修改 iCafe 卡片；卡片管理由 `icafe-card-assistant` 处理。
- 不删除、清空或重排已有归档目录，避免误伤历史交付材料。
