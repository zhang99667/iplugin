# v0.13.2

## 目标

收窄 `best-of-web` 的触发方式，让它只通过 `/best-of-web` slash command 显式调用，避免自然语言中的“找权威资料”“最佳实践”“结合互联网”等表达误触发。同时优化 slash command 文案，减少模型只读取或总结 `SKILL.md` 的概率。

## 变更清单

- `best-of-web` skill 升级到 `0.1.2`。
- frontmatter description 改为命令式触发：仅 `/best-of-web` slash command 才触发。
- skill body 的触发边界同步收窄：普通自然语言请求不再触发本 skill。
- `/best-of-web` command 改为“显式激活 best-of-web skill 并执行研究流程”，不再把第一步写成 `Read and follow skills/best-of-web/SKILL.md`。
- README 的 skill 表和 command 表同步强调 `/best-of-web` 是唯一入口。
- `.claude-plugin/plugin.json` 与 `.codex-plugin/plugin.json` 版本升级到 `0.13.2`。

## 架构决策

- 保留 skill 文件作为唯一真源，slash command 只做显式入口和参数传递，不复制大段研究流程。
- 不再让“结合互联网”“最佳实践”“权威资料”等自然语言短语触发本 skill；这些短语只有作为 `/best-of-web` 参数时才进入本流程。
- command 中避免使用“Read and follow SKILL.md”作为第一步，因为这会诱导模型把动作理解为读文件，而不是调用能力并执行联网精选。

## 排除项及原因

- 不删除 `/best-of-web` command：用户的真实使用习惯就是命令触发。
- 不新增别名命令：保持入口唯一，减少触发歧义。
- 不修改 manifest keywords：保留 `best-of-web`、`web`、`research` 等关键词方便插件检索，但由 skill description 约束实际触发。
