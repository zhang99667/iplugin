# v0.21.17 - HTML 报告 CSS 组件化

## 目标

解决 `html-report` 的 `references/css-template.md` 单文件过重问题。原文件同时承载基础样式、代码高亮、diff viewer、媒体证据、目录、标签页、表格和骨架示例，读取成本高，也不利于维护者定位具体组件。

## 变更清单

- `skills/html-report/references/css-template.md`
  - 从完整 CSS 模板改为 CSS 组件装配说明、HTML 骨架和少量 JS 片段。
  - 明确最终 HTML 仍然必须内联 CSS/JS，不允许通过 `<link>` 依赖外部文件。
  - 记录按内容选择组件 CSS 的顺序和触发条件。
- `skills/html-report/references/css/`
  - 新增 `base.css`：页面、卡片、正式抬头、路径 chip、行内 code、响应式和打印兜底。
  - 新增 `code-diff.css`：代码块、复制按钮、`tok-*`、ASCII 图和 `.diff-card.diff-viewer`。
  - 新增 `interactions.css`：折叠区和 toast。
  - 新增 `media.css`：截图、录屏和关键帧证据块。
  - 新增 `diagram.css`：内联 SVG 技术图容器。

  - 新增 `sortable-table.css`：可排序表格基础样式。
- `skills/html-report/SKILL.md`
  - 将 `html-report` skill 版本升级到 `0.3.10`。
  - 补充 `references/css/*.css` progressive disclosure 路由。
  - 明确代码、日志、ASCII 图或 diff 出现时必须内联 `code-diff.css`。
- `skills/html-report/references/content-rules.md`、`visual-rules.md`
  - 将代码/diff 样式来源从大模板改为 `references/css/code-diff.css`。

- `.claude-plugin/plugin.json`、`.codex-plugin/plugin.json`
  - 插件版本升级到 `0.21.17`。

## 架构决策

- 组件 CSS 作为 skill 内部源文件维护，最终报告仍然是单文件 HTML。这样同时满足维护可分层、交付可离线打开两个约束。
- 不新增构建脚本。当前 HTML 报告由 agent 生成，直接按 `css-template.md` 的组件清单读取并内联 CSS，成本最低。
- 复制按钮归入 `code-diff.css`，因为它只服务 `.code-wrap`；折叠和 toast 归入 `interactions.css`，因为它们是通用交互。
- `base.css` 保留 `--code-bg` / `--code` 变量，避免代码组件重复定义主题变量，同时保持组件内联顺序简单。

## 排除项及原因

- 不把最终 HTML 改为外链 CSS：HTML 报告的核心契约是离线单文件交付，外链会破坏可移植性。
- 不引入 CSS 打包脚本：本次目标是降低模板维护成本，不改变报告生成链路。
- 不调整 `highlight_code.py` 和 `check_html_report.py`：代码片段结构、diff viewer 闸门和校验规则已经稳定，本次只拆维护层 CSS 来源。
