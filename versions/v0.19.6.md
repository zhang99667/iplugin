# v0.19.6 - HTML 报告行内 code 换行修复

## 目标

修复 `html-report` 模板中普通行内 `<code>` 使用 `white-space: nowrap`，导致长命令、长路径或 Gradle task 撑破正文的问题。

## 变更清单

- `skills/html-report/SKILL.md`
  - 将 skill 版本升级到 `0.3.3`。
- `skills/html-report/references/css-template.md`
  - 将普通 `code` 从 `white-space: nowrap` 改为 `white-space: normal`、`overflow-wrap:anywhere` 和 `word-break:break-word`。
  - `pre code` 显式保留原始缩进，不受行内 code 换行策略影响。
- `.claude-plugin/plugin.json` / `.codex-plugin/plugin.json`
  - 插件版本升级到 `0.19.6`。

## 架构决策

- 优先修模板 CSS，而不是为某个报告单独写特殊 class；问题本质是普通行内 code 的默认 nowrap 不适合报告里的命令/路径。
- 保留 `pre code { white-space: pre; }`，避免破坏真正代码块、ASCII 图和 diff 的格式。

## 排除项及原因

- 不改校验脚本：这次只修模板默认样式，避免把一次视觉反馈扩大成新的校验策略。
- 不增加新的写作规则：现有响应式规则已经覆盖“不能撑破页面”，本次只补模板实现。
