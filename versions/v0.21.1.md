# v0.21.1 - Comate 图片 Prompt 清洗

## 目标

修正 `comate-image` 的 prompt 提炼规则：`Comate`、`banana2`、`gptimg2` 等词只用于触发 skill 或选择接口链路，不能默认进入最终图片 prompt。

## 变更清单

- `skills/comate-image/SKILL.md`
  - skill 版本升级到 `0.1.1`。
  - 触发范围补充“生成图片 / 出图”这类自然表达。
  - 明确 `Comate`、`gptimg2`、`gpt-image-2`、`banana`、`banana2`、`responses`、`生成图片`、`出图`、`prompt 是` 等路由词必须从最终图片 prompt 中剥离。
  - 明确用户只是泛泛说“生成图片”时默认走 `images + gpt-image-2`，不先询问模型；只有用户要求选择或比较链路时才询问。
- `skills/comate-image/scripts/comate_image_client.py`
  - 默认清洗 prompt 前后缀中的路由词。
  - 支持 `gptimg2`、`gpt-image-2`、`banana2` 等 backend 别名。
  - 新增 `--raw-prompt`，用于用户确实想把路由词作为画面内容的少数场景。
- `skills/comate-image/references/comate-image-apis.md`
  - 补充 backend 别名和 `--raw-prompt` 说明。
- `README.md`
  - 更新 `comate-image` 描述和触发示例。
- `.claude-plugin/plugin.json` / `.codex-plugin/plugin.json`
  - 插件版本升级到 `0.21.1`。
- `CHANGELOG.md`
  - 新增 `0.21.1` 版本记录。

## 架构决策

- prompt 清洗默认开启，因为触发词和选路词是 agent 控制信息，不是图像内容。
- 不把“每次选择模型”作为默认流程；默认链路保持 `images + gpt-image-2`，减少 agent 自动调用时被无意义打断。
- 保留 `--raw-prompt` 作为显式逃生口，覆盖用户确实想绘制 `Comate` 字样、模型名或产品名的场景。

## 排除项及原因

- 不新增全局配置保存默认模型：当前只需要把路由词从 prompt 中剥离，默认模型仍写在 skill 和脚本中。
- 不实现复杂自然语言解析器：本次只清理 prompt 开头和结尾的常见路由表达，避免误删画面主体中的普通描述。
