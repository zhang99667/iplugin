# v0.21.5 - delegated-search 复杂任务委派优化

## 目标

把 `delegated-search` 从偏“广域检索”的能力描述调整为复杂任务前置委派路由，让 Agent 在复杂排查、调用链找全、影响面分析、跨模块实现和并行验证场景中更容易先判断是否拆子 Agent。

## 变更清单

- `skills/delegated-search/SKILL.md`
  - skill 版本升级到 `0.1.3`。
  - frontmatter description 增加“拆子 agent / 并行 agent / explorer / worker”、复杂排查、完整链路、影响面分析、根因定位等触发语义。
  - 将目标从“广域检索、证据收集”扩展为复杂任务委派，明确历史名称仅保留兼容。
  - 增加强阈值：预计读取 5 个以上文件、跨 3 个以上目录/模块/仓库、输出超过 200 行、涉及 2 条以上独立线索等场景必须先做委派判断。
  - 增加 explorer / worker / verifier 角色映射，覆盖只读调查、有界实现和并行验证。
  - 增加子 Agent 不可用或判断不委派时的 fallback 和可见说明要求。
- `README.md`
  - 将插件能力描述和 Skills 表中的 `delegated-search` 用途更新为复杂任务委派。
- `.claude-plugin/plugin.json` / `.codex-plugin/plugin.json`
  - 插件版本升级到 `0.21.5`。
  - 将描述从“广域检索委派”更新为“复杂任务委派”。
  - 增加 `subagent`、`parallel`、`agent` 关键词。
  - Codex 默认提示更新为复杂任务拆给 explorer/worker 子 Agent 并行调查、实现或验证。
- `CHANGELOG.md`
  - 新增 `0.21.5` 版本记录。

## 架构决策

- 保留 skill 名称 `delegated-search`，不在本次改名。名称虽然偏搜索，但已有入口和文档都引用它；本次先通过 description、目标和触发阈值修正行为，避免引入迁移成本。
- 不把它改成通用联网搜索能力。公开互联网权威资料检索仍由 `best-of-web` 承担；本 skill 负责复杂任务拆分和子 Agent 协作，网页资料只是可能的数据源之一。
- 只升级 patch 版本，因为本次是已有 skill 的触发和执行规则优化，没有新增 skill。

## 排除项及原因

- 不新增 `delegated-task` 或 `agent-delegation` 新 skill。两个入口会造成重复维护和触发竞争，先用兼容方式优化现有 skill。
- 不强制所有复杂任务都必须实际委派。当前平台可能没有子 Agent 工具，或工具规则要求用户授权；skill 要求先判断并说明 fallback，而不是越过平台规则。
- 不新增 eval workspace。当前修改来自明确用户反馈和一次只读 explorer 审查，后续如果要量化触发率，再单独做 description trigger eval。
