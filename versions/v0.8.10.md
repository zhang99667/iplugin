# v0.8.10

## 目标

修正 `html-report` 源码定位展示的残余歧义：行号范围必须并入同一个可跳转文件 chip，不能再生成单独的行号 badge。

## 变更清单

- `html-report` 升级到 `0.2.9`
  - 明确 `{displayPath}:{start}-{end}` 是源码范围定位的唯一展示形式
  - 禁止“路径链接 + 单独行号 chip”的两段式定位
  - 从 CSS 模板移除 `.line` 样式，避免模型继续生成独立行号 badge
  - 明确源码定位由 HTML 结构驱动，CSS 只负责视觉样式，不能靠 CSS 合并错误结构
- 插件版本升级到 `0.8.10`，同步更新 Claude Code 与 Codex manifest

## 架构决策

- 文件路径和行号范围属于同一个定位实体，应该在一个可点击 chip 里完整表达。
- IDEA 跳转链接只需要使用起始行，展示文本必须保留完整范围，例如 `FlowVideoLandscapeHelper.kt:43-50`。
- 参考主流代码评审 UI 的分工：文件定位是单个文件头/链接实体，行号只在 diff 内容内部作为 gutter 出现；不要在问题元信息里另起一个行号 badge。

## 排除项及原因

- 不修改 `idea://open` 协议：IDEA 跳转按起始行打开即可，范围只用于阅读展示。
- 不新增额外 JS：这是模板和规范问题，不需要运行时逻辑。
