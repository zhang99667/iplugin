# v0.22.25 - HTML Report 批注筛选与快速定位

## 目标

让批注列表在内容变多后仍能快速扫描和回到正文，同时保持上一批确定的入口职责和 `AgentQuestionPack` 交接格式不变。

## 变更清单

- 侧栏新增 `全部`、`提问`、`注释` 三个分段筛选视图，并显示各自数量。
- 批注原文摘录改为可点击的快捷定位入口；已有显式 `定位` 按钮继续保留。
- 筛选状态仅保留在当前页面会话，不写入 localStorage 批注数据或 HTML 内嵌包。
- 校验器、组件回归、零依赖运行时测试、标准 Gallery 和评论模式 eval 同步增加筛选/定位门禁。
- `html-report` skill 从 `0.7.4` 升级到 `0.7.5`，插件从 `0.22.24` 升级到 `0.22.25`。

## 架构决策

- 使用 `data-qa-filter` 和本地 `annotationFilter` 管理视图，不给批注对象增加字段，避免改变 Agent 回写协议。
- 筛选只改变列表渲染；批注原数组顺序、保存、导出和发布版物理剥离逻辑继续复用原实现。
- 原文摘录使用现有 `locateAnnotation`，因此仍受 blockId 校验、唯一文本迁移和失效提示保护。

## 排除项及原因

- 本批不加入待处理/已处理状态、Agent 回复线程或批注 schema 版本升级，避免把列表浏览优化和协作数据模型绑定在一起。
- 本批不移除显式定位按钮，给不熟悉可点击原文的用户保留可见备用入口。
