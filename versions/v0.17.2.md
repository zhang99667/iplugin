# v0.17.2 — 删除与 skills 重复的 commands

## 目标

消除 `commands/` 目录下与 `skills/` 目录功能重复的文件，避免 harness 将同一能力重复注册为两个 skill 条目。

## 背景

Claude Code 的 plugin 体系中，`commands/` 和 `skills/` 都会被注册到 skills 列表中。iplugin 的以下三个 command 与同名 skill 功能完全重复：

- `commands/htmlreport.md` ↔ `skills/html-report/SKILL.md`
- `commands/ask-user-question.md` ↔ `skills/ask-user-question/SKILL.md`
- `commands/best-of-web.md` ↔ `skills/best-of-web/SKILL.md`

导致用户 context 中出现两个条目（一个英文 description、一个中文 description），浪费 token 且语义混乱。

## 变更清单

- 删除 `commands/htmlreport.md`
- 删除 `commands/ask-user-question.md`
- 删除 `commands/best-of-web.md`
- `commands/` 目录保留（未来非重复 command 仍可使用）
- 版本号升级到 `0.17.2`

## 决策

- 保留 `commands/` 目录结构，只删除与 skills 重复的文件
- skill 的 description 已包含 `/htmlreport`、`/ask-user-question`、`/best-of-web` 触发说明，不需要额外 command 入口
- 不修改 iplugin 加载逻辑，通过删除源文件解决问题
