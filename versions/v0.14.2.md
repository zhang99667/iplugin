# v0.14.2

## 目标

优化 `obsidian` skill 的图示表达策略，让写笔记时先判断哪种介质最清晰，再选择 Mermaid、ASCII、SVG/矢量图或图像生成来呈现链路、结构和概念。

## 变更清单

- `obsidian` skill 升级到 `0.1.1`。
- 新增“示意图表达策略”小节，明确图示的唯一目标是提升读者理解。
- 明确 Mermaid 优先用于流程、时序、状态、依赖和关系图。
- 明确 ASCII / `plain` 只适合很短、无分支的线性示意。
- 增加 SVG/矢量图和图像生成的适用场景。
- README 更新 `obsidian` 能力说明。
- 两个 manifest 的插件版本升级到 `0.14.2`，关键词补充 diagram、mermaid、image。
- CHANGELOG 增加 `0.14.2` 版本记录。

## 架构决策

- 不新增独立 diagram skill：该规则只服务 Obsidian 笔记写作时的表达选择，放在 `obsidian` 内更直接。
- 不把 Mermaid 设为强制：复杂结构优先 Mermaid，但空间表达、概念图和视觉解释仍允许选择 SVG 或图像生成。
- 不要求在最终笔记中暴露介质选择过程：除非用户需要，最终文档只呈现最清晰的结果。

## 排除项及原因

- 不增加图片生成脚本：图片生成依赖当前环境可用工具，skill 只定义选择规则和写作约束。
- 不调整 Obsidian 基础排版规则：本次只优化图示表达策略，避免混入无关格式变更。
