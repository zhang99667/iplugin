# v0.13.6

## 目标

修复 `html-report` 长文档目录交互：恢复旧版浮动侧栏视觉，只新增目录侧栏整体收起/展开能力，避免把目录做成只折叠内部标题链接的 `<details>` 结构。

## 变更清单

- `html-report` skill 升级到 `0.2.17`。
- `css-template.md` 的左侧目录恢复为旧版 `<aside class="toc">` 浮动卡片结构：
  - `.toc-title` 展示目录标题。
  - 章节链接直接作为 `.toc` 下的锚点元素。
  - 新增 `.toc-toggle` 按钮控制侧栏整体收起/展开。
  - 新增 `.layout-with-toc.toc-collapsed` 收起态，只保留窄栏按钮。
- `content-rules.md` 和 `visual-rules.md` 同步要求目录侧栏整体收起，而不是折叠目录内部链接。
- `check_html_report.py` 改为检查 `.toc-title`、`.toc-toggle`、`.toc-collapsed` 和目录锚点，并拒绝 `<details class="toc-details">` 目录结构。
- README 与两个 manifest 版本升级到 `0.13.6`。

## 架构决策

- 保留旧版浮动侧栏视觉作为默认，因为它更符合长文档快速定位的阅读场景，也比顶部目录或内部折叠目录更稳定。
- 不继续使用 `<details class="toc-details">` 承载目录，因为它只能收起目录内容，无法表达“整个目录侧栏收起来”的用户期望。
- 侧栏收起只使用少量内联 JS 切换 class，保持单文件离线 HTML，不引入外部依赖。

## 排除项及原因

- 不增加当前章节滚动高亮：收益有限，会引入更多滚动监听和状态管理。
- 不把目录链接包进额外 `<nav class="toc-panel">`：为保持旧版结构和视觉，锚点继续直接放在 `.toc` 下。
- 不在移动端做悬浮抽屉：窄屏下目录仍退化为顶部普通卡片，避免遮挡正文。
