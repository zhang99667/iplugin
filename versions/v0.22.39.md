# v0.22.39 - 透视表样式兼容修复

## 目标

修复 `nad-acx-pivot-table` 生成文件缺少 Excel 内建 Normal 命名样式的问题，并让 OOXML 闸门能够在交付前识别同类样式损坏。

## 变更清单

- `styles.xml` 补齐 `cellStyles/Normal`、`dxfs` 和 `tableStyles`
- guard 校验 workbook styles 关系和 `[Content_Types].xml` 声明
- guard 校验样式集合计数、引用索引边界和 styleSheet 子元素顺序
- 增加正常生成、缺少 Normal、关系缺失、Content Type 缺失和索引越界回归测试

## 架构决策

- 样式兼容校验放入现有 `ooxml_guard`，单透视与多透视入口共享同一闸门
- 继续使用标准库解析 OOXML，不增加运行时依赖
- 把兼容约束沉淀到 `references/ooxml_pitfalls.md`，不在 `SKILL.md` 复制实现细节

## 排除项及原因

- 本版本不扩展多层行轴或列轴能力；该问题与本次恢复日志指向的样式缺陷无关
- 静态闸门不能替代真实 Microsoft Excel 打开、刷新、保存和重开验收
