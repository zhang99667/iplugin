# v0.16.0

## 目标

新增一个本地离线的 Codex / Claude session 归档工具，提供类似“硅碳双键”的 session 备份和恢复能力，但不上传如流、不依赖知识库、不处理 ugate token。

## 变更清单

- `scripts/local_session_archive.py`：新增本地归档脚本，支持 `sync`、`watch`、`list`、`status`、`restore`。
- `skills/local-session-archive/SKILL.md`：新增本地 session 归档 skill，定义触发边界、恢复确认规则和常用命令。
- `README.md`：插件能力清单、目录结构和 Skills 表格加入 `local-session-archive`。
- `.claude-plugin/plugin.json` / `.codex-plugin/plugin.json`：插件版本升级到 `0.16.0`，描述和关键词加入本地 session 归档能力。
- `CHANGELOG.md`：记录本次新增能力。

## 架构决策

本工具只做本地文件归档，默认扫描 Codex 的 `~/.codex/sessions` 和 Claude 的 `~/.claude/projects` / `~/.claude/sessions` 下的 JSONL 文件，并复制到 `~/.local/share/iplugin/session-archive`。归档以 SHA256 判断是否变化，避免重复复制；每次实际复制都会追加 `index.jsonl`，供列表和恢复使用。

恢复默认写入归档目录下的 `restored/`，而不是直接覆盖原始 session 路径。只有用户明确要求并确认风险时，才使用 `--to-source` 或 `--overwrite`。

## 排除项及原因

- 不对接 KU / 如流：用户明确希望“存在本地”，本版本只提供离线归档。
- 不实现后台 daemon / launchd：先保留前台 `watch`，降低常驻进程、权限和日志维护成本。
- 不改写 JSONL 内容：归档工具只复制文件，不解析或重排 session，避免破坏 `codex resume` / Claude 读取兼容性。
