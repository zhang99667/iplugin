# v0.22.32 - HTML Report 批注版保持原文件名

## 目标

让用户 review 完保存批注版时始终使用当前 HTML 的原始文件名，方便直接覆盖原文件，避免 `_reviewed`、`_copy` 等后缀把 Agent 引向错误副本。

## 变更清单

- `保存批注版` 的文件选择器继续建议当前文件名。
- 浏览器不支持 File System Access API 时，下载兜底也使用当前文件名。
- 删除批注版 `_reviewed` 和 `_copy` 后缀生成逻辑。
- `导出发布版` 继续使用 `_public` 后缀。
- 同步更新校验器、组件测试、Gallery、批注契约和版本记录。
- `html-report` skill 从 `0.7.10` 升级到 `0.7.11`，插件从 `0.22.31` 升级到 `0.22.32`。

## 架构决策

- 当前 HTML 文件名是批注轮次的稳定身份，保存批注版时不再通过派生文件名规避覆盖。
- 静态页面仍不能静默覆盖本地文件；支持文件选择器时由用户选择原文件覆盖，不支持时由浏览器发起同名下载。
- 发布版不是批注回写目标，继续保留 `_public` 以避免误覆盖内部评论版。

## 排除项及原因

- 不修改 Clipboard 批注包、Agent 回执和本地草稿逻辑。
- 不改变发布版内容剥离或 `_public` 命名规则。
- 不尝试绕过浏览器的下载重名策略或文件覆盖确认。
