# v0.24.0 - material-exp-gate

## 目标

把「物料优先、实验兜底」收成可复用 skill：读全量 git diff，判断新逻辑是否被新物料/新字段控制；拦不住才加实验开关。不是 CR，不绑定任何需求。

## 变更清单

- `skills/material-exp-gate/SKILL.md`
  - 职责收成 check + 加实验开关
  - 强制先圈定 git diff 再追调用入口
- `skills/material-exp-gate/references/gate-rules.md`
  - 两种闸门、diff 读法、打点位置、误区
- README、两个 plugin manifest、CHANGELOG
  - 注册新 skill，插件版本升级到 `0.24.0`

## 架构决策

- 读 diff 只为判断「不发新字段还会不会执行」，不为挑代码问题。
- 物料能拦住就不加实验；实验只打在旧料也会走进的分叉点，默认关。
- 规则保持通用：不写卡片号、业务类名、具体云控 key。
- 加开关时跟随仓库现有实验读取方式，不另起一套，不改回落后的线上逻辑。

## 排除项及原因

- 不 review 代码质量、不改业务、不补物料/协议。
- 不附带任何需求对照样本，避免 skill 和一次性项目绑死。
- 不新增 slash command：自然语言触发足够。
