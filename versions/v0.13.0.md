# v0.13.0

## 目标

新增 `aidisheng-xueba` skill，让模型在爱迪生考试和连续答题场景中，不依赖固定选项字母，而是按题干和选项内容快速匹配已背题库并输出答案。

## 变更清单

- 新增 `skills/aidisheng-xueba/SKILL.md`，定义触发边界、答题流程和易混题提醒。
- 新增 `skills/aidisheng-xueba/references/question-bank.md`，沉淀单选题和多选题的正确内容、常见错误项和记忆点。
- 自我更新流程采用“标准答案反馈 → 更新基础题库 → 回放验证”的外部记忆闭环。
- README 增加 `aidisheng-xueba` 目录说明和 Skills 表格条目。
- `.claude-plugin/plugin.json` 与 `.codex-plugin/plugin.json` 版本升级到 `0.13.0`，补充爱迪生答题相关描述和关键词。

## 架构决策

- 题库以“正确内容”为真源，不把选项字母作为固定答案，因为考试题会打乱选项顺序。
- `references/question-bank.md` 是唯一持久化题库；当用户给出未见过题目或“标准答案”时，模型应把字母转换为当前选项内容并直接更新基础题库，避免下次选项换序失效。
- 不把“自我进化”理解为模型训练或权重更新；本 skill 使用可审计的文件记忆和明确覆盖规则来持续改进。
- 不接入 KU 或外部查询；当前 skill 只回答已经背下来的题库，未收录题目需要明确说明并谨慎推断。

## 排除项及原因

- 不新增 slash command：用户可通过自然语言“爱迪生学霸”或连续答题上下文触发，无需额外命令入口。
- 不运行带 skill/baseline 的完整评测：本次题库有明确标准答案，先通过人工题库结构和插件校验保证可用。
