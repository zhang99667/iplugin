# v0.8.3

## 目标

补齐 `html-report` 已声明的 `/htmlreport` slash command 入口，并把依赖人工记忆的提交前检查沉淀为可重复执行的本地校验脚本。

## 变更清单

- 新增 `commands/htmlreport.md`
- `/htmlreport` 命令读取并复用 `skills/html-report/SKILL.md`，只做轻量参数解析和编排
- 更新 README 的 Commands 列表，明确 `/ask-user-question` 与 `/htmlreport` 两个用户可见命令
- 新增 `scripts/validate-plugin.py`
  - 校验 `.claude-plugin/plugin.json` 与 `.codex-plugin/plugin.json` 是合法 JSON
  - 校验两个 manifest 的公共字段一致
  - 校验 `skills/<name>/SKILL.md` 的 frontmatter 必填字段和目录名一致性
  - 校验 README Skills 表与实际 skill 目录一致
  - 校验 manifest keywords 覆盖所有 skill 名称和 kebab 拆分关键词
  - 校验 CHANGELOG 中的版本都存在 `versions/vX.Y.Z.md` 或 `versions/vX.Y.Z/`
  - 校验 command 中引用的 skill 存在，并检查 README/skill 中声明的 slash command 是否有对应 command 文件
- AGENTS.md 与 CLAUDE.md 的提交前检查补充校验脚本
- manifest 关键词补齐所有 skill 名称及拆分关键词
- 插件版本升级到 `0.8.3`，同步更新 Claude Code 与 Codex manifest

## 架构决策

- 将 `/htmlreport` 作为 command 层入口，而不是复制 HTML 报告生成逻辑，继续保持 `skills/html-report/SKILL.md` 为唯一能力真源。
- 命令被调用时视为用户已明确要求 HTML，因此跳过 HTML vs Markdown 的二次确认；但仍保留 `html-report` skill 对正式文档、分析报告和普通对话整理的内容类型判断。
- 当命令没有参数时，从最近回答、结论、评审结果或当前任务上下文推断报告来源，符合用户使用 slash command 快速整理当前内容的习惯。
- 校验脚本使用 Python 标准库实现，不引入额外依赖，方便在任意本地环境直接运行。
- validator 只读仓库文件并输出 PASS/FAIL，不自动修复，避免提交前检查意外改动工作区。

## 排除项及原因

- 不改动 `html-report` skill 本体：本次只补齐缺失的命令入口，避免顺手扩大视觉规范或报告生成策略。
- 不删除 README 和 skill 中已有 `/htmlreport` 文案：这些文案现在有真实 command 对应。
- 不接入 git hook：当前先保留手动运行，避免改变用户提交流程；后续确认稳定后再考虑 pre-commit 或插件刷新流程集成。
- 不自动更新 README 或 manifest：自动修复容易误改描述口径，先由脚本报告问题，人工确认后修改。
