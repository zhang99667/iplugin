# v0.22.34 - HTML Report 代码块边界兼容修复

## 目标

补齐代码块语言标签和悬停复制上线后的边界行为，确保关闭复制、历史工具栏、打印和窄屏布局都保持可验证且可读

## 变更清单

- `--no-copy` 输出在 `.code-wrap` 上显式标记 `data-copy="false"`，校验器不再把有意关闭复制误判为缺陷
- runtime 每次初始化都把 `.code-lang` 放到工具栏末尾，并将历史复制按钮插入其前方，统一语言标签右上角位置
- 校验器对新生成结构检查工具栏顺序、`data-code-lang` 与 `language-*` 的一致性，同时保留无新标记旧报告兼容
- 打印模式将语言 chip 切换为浅色背景和深色文字，窄屏下复制按钮不换行、语言标签可收缩省略
- 更新组件测试、Gallery、插件资产门禁和版本记录
- `html-report` skill 从 `0.7.12` 升级到 `0.7.13`，插件从 `0.22.33` 升级到 `0.22.34`

## 架构决策

- 使用显式 `data-copy="false"` 区分“有意无复制”和“误删复制按钮”，不放宽所有 `.code-wrap` 的复制门禁
- 只对带 `data-code-lang` 的新生成结构执行严格顺序和元数据校验；旧 HTML 仍交给 runtime 渐进增强
- 语言标签保留在打印版，确保纸面或 PDF 导出仍能识别代码语言，而不是直接隐藏整个工具栏

## 排除项及原因

- 不修改 Diff viewer 的标题和文件标识，避免重复显示语言信息
- 不改变复制 API 和失败回退逻辑，本次只修正结构、布局和门禁
