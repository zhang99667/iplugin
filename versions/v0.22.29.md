# v0.22.29 - HTML Report 批注侧栏紧凑化

## 目标

降低批注卡片的视觉占用，并减少批注侧栏常用文件操作的点击层级，让连续审阅和交付更直接。

## 变更清单

- 批注卡片设置 12px 基础字号，批注正文同步从 13px 收敛到 12px；按钮原文摘录不再继承报告正文的大字号。
- 移除重复的 `复制 Markdown` 和 `下载 Markdown` 按钮；`复制批注给 Agent` 继续生成完整 Markdown 批注包。
- 移除空余的“更多操作”折叠层，将 `保存批注版` 与 `导出发布版` 并排展示。
- 将 `清空本轮` 提升为直接可见的危险操作，继续保留二次确认。
- 同步批注模式契约、校验器、组件回归、Gallery、eval 和版本记录。
- `html-report` skill 从 `0.7.7` 升级到 `0.7.8`，插件从 `0.22.28` 升级到 `0.22.29`。

## 架构决策

- `复制批注给 Agent` 已覆盖 Markdown 交接，因此删除重复入口而不改变 `buildMarkdownPack()` 和剪贴板兜底协议。
- 文件操作保持清晰层级：复制交接是主操作，保存和发布是并列次级操作，清空是独立危险操作。
- 继续复用既有 HTML 保存、发布版剥离和清空确认逻辑，只调整入口结构和样式，避免扩大回归面。

## 排除项及原因

- 不修改 `AgentQuestionPack`、`AgentReviewReceipt` 或本地草稿 schema；本次只优化批注侧栏展示。
- 不改变保存批注版与导出发布版的文件选择、下载兜底和命名逻辑。
- 不重做批注卡片结构、颜色或操作集合；现有定位、编辑、复制单条和删除行为保持不变。
