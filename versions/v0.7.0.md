# v0.7.0 广域检索委派

## 目标

新增一个通用 skill，用于处理发散搜索、证据收集、多来源核验、链路定位等容易消耗主线程上下文的任务。

## 变更清单

- 新增 `delegated-search` skill。
- 插件版本从 `0.6.1` 升级到 `0.7.0`。
- 更新 Claude Code 与 Codex manifest 的描述和关键词。
- 更新 README、CHANGELOG 和维护指南中的插件定位，避免把 iPlugin 限定为某个单一软件。

## 架构决策

- skill 不绑定代码任务，覆盖代码、文档、日志、配置、历史记录、网页资料和数据文件。
- skill 不要求用户显式说“使用子 agent”才触发；执行助手根据任务宽度自行判断是否委派。
- 主线程仍负责最终判断、关键证据抽查和用户交付，explorer/subagent 只承担搜索与证据收集。
- 如果当前环境需要授权才能使用子 agent，执行助手先询问；如果不可用，则退化为紧凑本地检索。

## 排除项

- 不新增具体 subagent 实现。本版本只沉淀通用判断和协作规范。
- 不把该能力限定为代码阅读，因为广域检索同样适用于文档、日志、网页和数据分析场景。
