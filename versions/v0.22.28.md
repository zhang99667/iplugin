# v0.22.28

## 目标

修复 `nad-acx-pivot-table` 多业务合并场景下 Excel 打开报“内容有问题/尝试恢复”，并补齐“一个实验号多个业务方”的原生能力。

## 变更清单

- 新增 `skills/nad-acx-pivot-table/scripts/pivot_tool/merge_pivots.py`
  - 支持多个 `(CSV, config)` 合并为一个多 sheet 工作簿
  - 每个有数据业务生成独立 pivotTable/cache，sheet 顺序与传入顺序一致
  - 空数据业务只保留占位 sheet，不生成空 pivotTable/cache
  - 有数据业务按顺序分配唯一 `cacheId`，并与 workbook `pivotCaches` 一致
- 修改 `skills/nad-acx-pivot-table/scripts/pivot_tool/pivot_table.py`
  - 多级行字段生成完整两级 `rowItems`，避免相对差列 `#N/A`
  - `location` 高度与 `rowItems` 数量保持一致
- 修改 `skills/nad-acx-pivot-table/SKILL.md`
  - 新增“多业务合并”用法与注意事项
  - skill 版本从 `0.1.4` 升到 `0.1.5`
- 插件版本从 `0.22.27` 升到 `0.22.28`

## 架构决策

- 多业务工作簿不沿用 7.15 模板的旧 cacheId 映射，而是按“有数据业务”动态分配连续 `cacheId`，从 0 开始
- 空数据业务不写 pivotCache/pivotTable 部件，避免 Excel 对“0 行 cache + dataFields”结构判定损坏
- 所有 `[Content_Types].xml` 声明只包含实际存在的部件，避免悬空引用

## 排除项

- 不处理 LibreOffice 对 `percentDiff` 显示为空的问题：这是 LibreOffice 自身限制，Excel 正常显示
- 不修改单文件生成流程，只新增多业务合并能力
