# v0.17.0

## 目标

新增一个 DataPilot SQL 跑数闭环 skill，把“准备 SQL、打开 DataPilot、粘贴到 Monaco 编辑器、点击 run、回收任务 ID、汇报状态”沉淀成可复用流程。它补齐 `sql-exp-replace` 和 `commercial-sql-writer` 之后的实际跑数环节，适合内部 DataPilot 页面需要 Chrome 登录态的场景。

## 变更清单

- `skills/datapilot-sql-runner/SKILL.md`：新增 DataPilot SQL 跑数 skill，定义触发边界、SQL 预处理、Chrome 操作、任务 ID 回收、状态解析和故障处理。
- `README.md`：插件能力清单、目录结构和 Skills 表格加入 `datapilot-sql-runner`。
- `.claude-plugin/plugin.json` / `.codex-plugin/plugin.json`：插件版本升级到 `0.17.0`，描述和关键词加入 DataPilot SQL 跑数能力。
- `CHANGELOG.md`：记录本次新增能力。

## 架构决策

DataPilot 是内部站点，实际操作依赖用户已有 Chrome 登录态，因此 skill 不直接实现 HTTP API 或凭据读取，而是明确优先使用 Chrome 插件接管现有 DataPilot 标签页。SQL 输入保持文件或附件原文不变，涉及实验号/日期替换时复用 `sql-exp-replace`，提交版写入 `/private/tmp`，避免污染原始 SQL。

DataPilot 的 SQL 编辑器是 Monaco，多标签场景会保留隐藏 textarea。skill 将“动态选择可见 `textarea.inputarea`”作为核心操作约束，避免固定索引导致粘贴到隐藏编辑器。任务状态解析按 `任务ID:<id>` 到 `ID:<id>` 的卡片边界截取，避免把相邻旧任务的成功/失败状态串进当前任务。

## 排除项及原因

- 不新增脚本：当前浏览器操作强依赖页面状态和 Chrome 插件，先用 skill 流程沉淀即可。
- 不等待所有任务默认完成：DataPilot 中等任务可能排队较久，默认回收任务 ID 和初始状态；只有用户明确要求时再持续轮询结果。
- 不读取 cookies / localStorage / 密码：遵循 Chrome 插件安全边界，只使用已登录页面和公开 DOM 状态。
