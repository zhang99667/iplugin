# v0.22.18 - 状态标签可读性兜底

## 目标

修复 HTML 报告中裸 `.tag` 只有白色文字、没有默认背景，导致文字与白色卡片背景融为一体的问题。

## 变更清单

- `.tag` 增加中性深灰默认背景，P0/P1/P2 变体继续覆盖为红、橙、蓝。
- 打印模式把标签统一降级为浅底深字，避免打印引擎忽略彩色背景后留下不可见白字。
- 校验器在页面实际使用 `.tag` 时检查默认规则同时包含前景色和背景色。
- 新增正常标签与缺少默认背景的组件回归测试，eval 同步加入标签可读性要求。
- `html-report` skill 从 `0.6.3` 升级到 `0.6.4`，插件从 `0.22.17` 升级到 `0.22.18`。

## 架构决策

- 可读性由基础 `.tag` 自身兜底，不依赖生成器每次都正确附加 `.p0/.p1/.p2`。
- 默认背景使用中性灰，避免给没有明确严重级别的标签制造红、橙、蓝语义。
- 保持现有标签 DOM 和变体类不变，已有报告结构无需迁移。

## 排除项及原因

- 不增加通用 CSS 对比度计算器：当前缺陷来自稳定组件缺少默认背景，直接修复资产并加入契约检查更可靠。
- 不修改正文、卡片或代码配色：这些区域没有出现同类前景/背景冲突。
