# v0.21.7 - Android mock 验收报告媒体证据内嵌优先

## 目标

收紧 Android mock 验收报告的证据呈现方式，避免报告只提供纯表格和文件超链接，导致读者需要跳转后才能复核每个 case 的截图或录屏证据。

## 变更清单

- `skills/android-mock/SKILL.md`
  - skill 版本升级到 `0.1.2`。
  - 明确多链路结果可以使用逐 case 卡片呈现。
  - 要求优先使用 `.case-card` 卡片，并在卡片内通过 `<figure class="media-evidence">` 直接内嵌截图或录屏预览。
  - 明确纯汇总表格和超链接只能作为补充，mock 日志、logcat 等原始文件链接不能替代卡片内的主证据。
- `.claude-plugin/plugin.json` / `.codex-plugin/plugin.json`
  - 插件版本升级到 `0.21.7`。
- `CHANGELOG.md`
  - 新增 `0.21.7` 版本记录。

## 架构决策

- 继续把验收报告约束放在 `android-mock` skill 内。`html-report` 仍保持通用报告能力，Android mock 这类强证据场景由调用方 skill 提出更严格的媒体证据要求。
- 仅升级 patch 版本，因为本次是已有 skill 的报告规范细化，没有新增 skill、command 或新的用户入口。

## 排除项及原因

- 不改 `html-report` 的通用模板要求。其他报告类型未必需要逐 case 卡片或媒体证据内嵌。
- 不新增 README 或 manifest 关键词。现有 Android mock、HTML 报告、图片/视频证据关键词已经覆盖这次变更。
