# v0.22.41 - 透视表枚举项完整性修复

## 目标

修复 `nad-acx-pivot-table` 在 `row_item_order` 只配置部分枚举值时生成损坏
`pivotTableDefinition` 的问题。该结构会让旧版 Mac Excel 在打开工作簿时崩溃。

## 变更清单

- `pivot_table.py` 将 `row_item_order` 解释为优先排序，自动追加未列出的实际枚举值
- 修正 `pivotField/items@count`，并让 OOXML guard 校验声明数量与真实 `<item>` 子节点数量
- 新增部分枚举排序和损坏 XML 故障注入回归测试
- 更新配置 schema、OOXML 踩坑记录与 skill 使用说明

## 架构决策

- 保留生成器现有的 sharedItems 顺序和索引契约，只在透视字段输出前补齐排序值
- guard 继续使用标准库解析 OOXML，不增加运行时依赖；数量校验作为生成阶段的最后防线
- 将行为定义为通用 skill 规则，不把 FEEDADS-24732 的具体枚举值写入插件

## 排除项及原因

- 不改变多级行字段第二层的排序逻辑；该问题与本次 `items/count` 崩溃根因独立，应另行补回归
- 不自动重跑 DataPilot 任务或修改业务项目台账；本次修复只影响透视表生成器和校验器
