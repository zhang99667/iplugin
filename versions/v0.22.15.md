# v0.22.15 - 批注提交快捷键提示

## 目标

让评论模式中已经支持的快捷提交能力可被用户直接发现，不再只依赖悬停标题或记忆。

## 变更清单

- 在批注输入浮层的唯一提交按钮内增加 `Ctrl/⌘ + Enter` 快捷键标识。
- 保留 `aria-keyshortcuts="Meta+Enter Control+Enter"`，不改变普通 Enter 换行、输入法组字保护和原有提交逻辑。
- 为快捷键标识增加紧凑的 `<kbd>` 样式，避免按钮文字在窄屏换行。
- 扩展 HTML 报告校验器、仓库资产检查和 eval，强制新生成的评论版显示快捷键提示。
- `html-report` skill 从 `0.6.0` 升级到 `0.6.1`，插件从 `0.22.14` 升级到 `0.22.15`。

## 架构决策

- 快捷键提示属于现有批注复合模块，不新增组件或 runtime。
- 使用按钮内的次级 `<kbd>` 标识，不增加帮助文案、第二个操作按钮或额外交互。
- `<kbd>` 对屏幕阅读器隐藏，按钮名称保持简洁的“提交”；快捷键语义由 `aria-keyshortcuts` 提供。

## 排除项及原因

- 不修改键盘监听逻辑：现有 `Ctrl/⌘ + Enter`、普通 Enter 和 IME 行为已经稳定。
- 不根据操作系统动态切换提示：静态双平台标识在离线单文件中更可靠，也无需增加脚本分支。
