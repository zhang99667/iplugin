# v0.22.19 - 评论类型徽标布局稳定

## 目标

修复评论卡片中长章节标题挤压“提问/注释”徽标，导致两个字竖排显示的问题。

## 变更清单

- `.qa-kind` 禁止 flex 收缩和文字换行，类型徽标始终保持横排。
- `.qa-section` 使用 `min-width: 0` 承担剩余空间收缩，并允许长章节标题正常换行。
- 评论模式校验器新增类型徽标和章节标题布局闸门。
- 组件回归测试覆盖缺少稳定宽度约束的错误样式，评论模式 eval 同步加入徽标横排要求。
- `html-report` skill 从 `0.6.4` 升级到 `0.6.5`，插件从 `0.22.18` 升级到 `0.22.19`。

## 架构决策

- “提问/注释”只在评论模式内部复用，不具备独立用户意图和装配边界，因此保持为复合模块内部子组件。
- 稳定性要求接入现有 `check_annotation_mode()`，不新增顶层注册组件或第二套校验入口。
- 完整保留长章节标题，通过换行分配空间，不用截断标题来掩盖布局问题。

## 排除项及原因

- 不修改评论卡片 DOM：现有语义结构正确，问题只来自 flex 收缩约束缺失。
- 不调整侧栏宽度：扩大容器不能解决分屏和窄窗口下的同类问题。
