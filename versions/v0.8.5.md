# v0.8.5

## 目标

把 `html-report` 和 `mgit` 两个长 skill 改为 progressive disclosure 结构，让 `SKILL.md` 只保留触发、导航和最短执行路径，把细节规则拆到 `references/` 按需读取，降低 skill 触发后的默认上下文负担。

## 变更清单

- `html-report` 升级到 `0.2.7`
  - `SKILL.md` 保留触发边界、references 导航、最短执行流程、输出契约和核心原则
  - 新增 `references/content-rules.md`，沉淀 HTML vs Markdown 决策、内容类型判断、正式抬头、输出要求、写作规范和完成前检查
  - 新增 `references/visual-rules.md`，沉淀视觉原则、文件定位链接、长文档目录、ASCII/代码块、交互组件和场景速查
  - 保留既有 `references/css-template.md` 作为生成 HTML 时才读取的样式和骨架模板
- `mgit` 升级到 `0.1.2`
  - `SKILL.md` 保留触发边界、references 导航、最短执行流程、安全底线和输出风格
  - 新增 `references/command-guide.md`，沉淀工作区识别、常用诊断、范围控制、状态/同步/分支/拉取/提交/推送/forall 和高风险命令
  - 新增 `references/config-troubleshooting.md`，沉淀 manifest、本地配置、中间态处理、输出风格和常见意图映射
- 插件版本升级到 `0.8.5`，同步更新 Claude Code 与 Codex manifest
- AGENTS.md / CLAUDE.md / README 补充 `skills/<name>/references/` 目录约定

## 架构决策

- 保留 frontmatter description 的触发信息，因为这是 skill 自动选择的关键入口。
- SKILL.md 只描述“什么时候用、怎么决定、何时读哪个 reference”，避免每次触发都加载全部细节。
- references 按使用场景拆分，而不是按原文顺序拆分：内容规则、视觉规则、样式模板；命令指南、配置与中间态。
- 不新增脚本，当前只是知识组织重构，不涉及确定性执行逻辑。

## 排除项及原因

- 不一次性拆分所有长 skill：先处理 `html-report` 和 `mgit` 两个最典型的长 skill，验证结构稳定后再迁移 `icafe-delivery-archive`、`project-summary`、`lite-diff-marker` 等。
- 不改动技能触发边界：`0.8.4` 已集中收窄触发条件，本次只做 progressive disclosure 组织调整。
- 不压缩 `css-template.md`：它本来就是按需读取的模板文件，保留完整内容更利于稳定生成 HTML。
