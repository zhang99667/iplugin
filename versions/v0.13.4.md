# v0.13.4

## 目标

明确 `html-report` 的 Pygments 增强高亮策略：增强高亮可以安装，但不能让普通 HTML 报告生成流程自动联网或静默改环境。

## 变更清单

- `html-report` skill 升级到 `0.2.16`。
- `highlight_code.py` 支持 Pygments Python 模块和 `pygmentize` CLI 两种本地预渲染形态。
- skill 主文件和 references 明确：默认使用轻量 `builtin`，`--engine auto` 只探测已有 Pygments，缺失时回退。
- 补充安装策略：只有用户明确要求安装/增强高亮时才安装；Homebrew Python 下优先用户级 pip 安装。
- README 与两个 manifest 版本升级到 `0.13.4`。

## 架构决策

- 保持轻量默认值，避免一次生成 HTML 报告隐式联网、安装依赖或修改用户环境。
- 将 Pygments 作为可选增强依赖，而不是插件硬依赖。
- 支持 `pygmentize` CLI，是为了兼容 Homebrew 或其他工具链安装的 Pygments，不强制要求 Python 模块可 import。

## 排除项及原因

- 不在脚本里自动执行安装命令：安装依赖是外部环境变更，必须由用户确认。
- 不使用 `--break-system-packages` 作为默认建议；只在 Homebrew Python 的 PEP 668 场景下作为用户级安装方案。
- 不把 Pygments 写进插件 manifest 依赖：插件仍应在无 Pygments 环境下可用。
