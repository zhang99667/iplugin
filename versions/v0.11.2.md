# v0.11.2

## 目标

优化 `html-report` 在问题排查/修复方案和代码块展示上的稳定性：常见排查报告有独立结构模板，代码高亮从手工 HTML span 改为脚本辅助生成。

## 变更清单

- `skills/html-report/SKILL.md` 升级到 `0.2.11`，补充 `scripts/highlight_code.py` 的 progressive disclosure 路由。
- 新增 `skills/html-report/scripts/highlight_code.py`，使用 Python 标准库把代码转成可嵌入 HTML 的 `.code-wrap` 片段，并支持 `--diff-view` 输出 old/new 行号修改点视图。
- 更新 `references/artifact-patterns.md`，新增“问题排查/修复方案”模板。
- 更新 `references/content-rules.md`、`references/visual-rules.md` 和 `references/css-template.md`，要求优先用脚本生成高亮代码块；脚本不可用时只做保守手工高亮。
- 插件 manifest 版本升级到 `0.11.2`。

## 架构决策

- 代码高亮不追求完整语法解析，只做 HTML 转义和基础 token 高亮；diff viewer 只解析 unified diff 的 hunk 行号，避免引入外部依赖或复杂构建链。
- 脚本支持 `kotlin`、`java`、`js`、`python`、`xml`、`diff`、`text`，覆盖当前 HTML 工程报告最常见代码片段。
- 问题排查/修复方案单独成模板，因为它的主线是现象、根因、证据和验证，不应被技术方案模板里的接口/数据结构章节稀释。

## 排除项

- 不新增浏览器渲染校验要求；当前保持代码级检查和插件结构校验，避免每次生成报告都增加额外耗时。
- 不新增独立 HTML artifact builder skill；仍由 `html-report` 承担工程 HTML 交付物生成。
- 不在本次覆盖选型报告、状态报告、代码评审报告等其他模板。
