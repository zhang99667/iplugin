# v0.23.0 - Codex CLI 会话导出

## 目标

为 Codex CLI 提供与 Grok TUI `export` 类似的统一导出入口，将交互会话和命令行任务归档为可读 Markdown。

## 变更清单

- 新增 `codex-session-export` Skill 和确定性 Python 导出脚本
- 支持选择当前会话、最近会话、Session ID 或明确的 JSONL 文件
- 同时解析 Codex 持久化 rollout JSONL、旧版消息 schema 和 `codex exec --json` 顶层事件
- 默认只导出 Markdown；仅在用户明确要求时附带经过基础脱敏和截断的工具调用详情
- 保留上游 `session-export` 项目的 MIT 许可证

## 架构决策

- Skill 以 `codex-session-export` 命名，因为当前实现只理解 Codex CLI 的本地数据格式；不以通用 `session-export` 名称暗示跨 Agent 兼容
- 解析、脱敏与 Markdown 渲染集中在一个标准库 Python 脚本中，Skill 只负责触发和参数编排
- 持久化会话与 `codex exec --json` 复用同一输出模型，保持交互执行和自动化执行的归档格式一致

## 排除项及原因

- 不支持 Claude Code、Cursor 或其他 Agent 的会话文件；这些工具的数据位置和 schema 不同，需要独立适配后再考虑通用入口
- 不抓取 Codex 云端任务；当前实现只读取本机文件
- 不导出没有持久化文件、也未保存 `codex exec --json` 输出的 `--ephemeral` 任务，因为本地不存在可恢复的数据源
- 不默认输出完整工具参数和结果，避免把项目数据或凭据直接带入归档
