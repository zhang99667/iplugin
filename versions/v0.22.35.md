# v0.22.35 - HTML Report 回到顶部

## 目标

为长篇 HTML 报告提供稳定的回到顶部入口，减少读者浏览到文末后重新定位首屏的操作成本，同时不影响短报告、打印和无 JavaScript 回退

## 变更清单

- 默认 `interactions` 组件新增 `runtime.js`，所有新装配报告自动获得回到顶部能力
- 页面滚动超过 360px 后显示右下角按钮，点击平滑返回顶部
- 隐藏状态同步使用 `tabIndex=-1` 和 `aria-hidden=true`，显示后恢复键盘操作
- 使用 passive scroll listener 和 `requestAnimationFrame` 合并滚动更新
- 尊重 `prefers-reduced-motion`，减少动态效果时立即返回顶部并关闭过渡
- 支持移动端安全区、打印隐藏和 `:focus-visible` 焦点样式
- 批注侧栏在桌面展开时按钮向左避让，移动端展开时完全隐藏
- runtime 使用 `window` 级防重复标记并复用已有按钮，修复导出 HTML 序列化动态节点但不保留事件监听的问题
- 更新组件测试、Gallery、插件资产门禁和组件契约
- `html-report` skill 从 `0.7.13` 升级到 `0.7.14`，插件从 `0.22.34` 升级到 `0.22.35`

## 架构决策

- 回到顶部属于所有报告共享的基础阅读能力，放入默认 Core `interactions`，不拆成需要正文标记触发的独立组件
- 按钮由 runtime 动态创建，无 JavaScript 时正文和原生 `<details>` 仍完整可用
- 批注侧栏冲突规则由 `annotation-mode` 自己维护，使导出发布版剥离批注资产时不残留 QA 专用选择器
- 使用 `window` 状态防止同一页面重复初始化；该状态不会被 HTML 序列化，因此导出文件重新打开后仍会重新绑定事件

## 排除项及原因

- 不增加进度环、滚动百分比或额外快捷键，保持单一回顶职责
- 不在短页面常驻按钮，避免无意义的视觉噪音
