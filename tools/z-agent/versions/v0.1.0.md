## 目标

创建第一版可运行的 z-agent 工具项目，用于采集 Ghostty 工作区快照，并恢复
Agent 会话。

## 变更清单

- 在 `tools/z-agent` 下创建 Python CLI 包。
- 默认在 `~/.local/share/z-agent` 维护 `workspace_state.json`。
- 分别支持 Codex 和 Claude Code 的 Agent 配置。
- 提供包装器入口，用于注入终端元数据。
- 提供 hook ingest，在不读取对话转录正文的前提下保存会话元数据。
- 支持恢复计划查看，并且只执行白名单内的恢复命令。
- 增加按 Agent 生成 hook ingest 脚本和原生 hook 配置示例的安装模板。
- 增加纯逻辑单元测试。
- 将用户可见文档、变更日志、版本记录和 CLI 文案改为中文。
- 为核心代码补充中文行间注释，便于审阅状态写入、hook 解析、恢复白名单和 Ghostty 执行边界。
- 为 `AgentSpec` 和 `WrapperContext` 补充字段级说明，避免只靠变量名推断 Agent 配置和 wrapper 上下文。
- 重写 README 使用说明，按首次上手路径说明安装、钩子合并、启动、采集和恢复。
- 修复命令行主入口解析器调用拼写错误，并增加覆盖普通子命令分发路径的测试。
- 收敛恢复命令：`zagent restore` 只负责恢复，不再暴露额外执行模式。

## 架构决策

- 可执行恢复动作存为结构化 `argv`，不只保存 shell 字符串。
- 保留可读的 `restore_cmd` 兼容字段，方便审阅。
- 状态写入使用锁文件和原子替换。
- terminal marker 命中视为高置信绑定，兜底匹配视为低置信绑定。
- `restore` 是执行命令，只负责控制 Ghostty 恢复工作区。
- `restore_cmd` 只作为展示兼容字段，真实执行只信任 `restore.argv`。
- `terminal_key` 表示 pane 身份，`run_id` 表示单次 Agent 进程启动。

## 验证记录

- `python3 -m unittest discover -s tests`：23 个测试通过。
- `python3 scripts/validate-plugin.py`：10 项插件结构校验通过。
- `Z_AGENT_INSTALL_ROOT=/tmp/z-agent-install-test python3 src/z_agent/cli.py install codex`：hook 安装文件写入正常。
- `python3 src/z_agent/cli.py snapshot capture --name test`：采集命令入口可用。

## 排除项

- 不接入 daemon 或 launchd。
- 不回放任意 shell 历史。
- 不自动修改 shell 配置文件。
- v0.1.0 不承诺精确恢复 split 像素比例。
