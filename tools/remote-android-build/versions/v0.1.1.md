# remote-android-build v0.1.1

## 目标

将工具的用户可见输出中文化，让初始化、帮助信息、错误提示和执行阶段提示与中文 README、维护文档保持一致。

## 变更清单

- `init-project.zsh`
  - 初始化成功、保留现有文件、错误提示改为中文。
  - 生成的 `.remote-build.zsh` 注释改为中文。
  - “下一步”操作提示改为中文。
- `remote-build.zsh`
  - `--help` 输出改为中文。
  - 参数错误、配置缺失、命令缺失、本地前置条件失败等提示改为中文。
  - 同步、远端编译、拉回 APK、安装和完成提示改为中文。
- `remote-build.env.example`
  - 示例文件注释改为中文。
- `README.md`、`CHANGELOG.md`、`versions/README.md`
  - 记录输出中文化的用户可见行为变化。

## 架构决策

- 只翻译面向人的说明文字，不翻译命令参数、环境变量和配置键名。
- 保留 `DRY_RUN`、`LOCAL_ROOT`、`REMOTE_ROOT`、`APK_GLOB` 等配置名，确保现有项目配置和自动化脚本无需迁移。
- 阶段序号仍保留 `[1/5]` 形式，方便用户快速定位执行进度。

## 排除项及原因

- 不引入 i18n 多语言切换。当前工具面向个人中文研发工作流，增加语言切换会提高维护复杂度。
- 不调整 rsync、ssh、adb 或 Gradle 的原生命令输出。这些输出来自外部工具，强行包装会降低排错透明度。
- 不改变默认构建任务、APK 路径和安装策略。本版本只处理输出语言。
