## 目标

创建第一版可运行的 Android 远程构建工具，用于把本地 Android 工程同步到远端 M4 Mac 编译，再把 APK 拉回本地安装。

## 架构决策

- 使用项目级 `.remote-build.zsh` 描述项目差异，而不是把业务工程写死在工具里。
- 初版只使用 SSH 和 rsync，先保证可理解、可排错、可回退。
- 远端 `REMOTE_ROOT` 只作为可丢弃镜像目录。
- `--dry-run` 和 `--no-install` 是命令行覆盖项，优先级高于配置文件。
- `adb` 只在需要安装 APK 时检查，允许无设备环境只做远程构建和拉包。

## 排除项

- 不自动安装或配置 Mutagen。
- 不自动配置 Gradle Remote Build Cache。
- 不处理 Tailscale、VNC 或公司网络策略。
- 不自动处理 split APK 或 AAB 安装。
- 不修改具体 Android 工程的 Gradle 文件。
