# remote-android-build v0.1.7

## 目标

让远端中间产物清理策略可以写进项目配置，不必每次靠命令行开关。

## 变更清单

- `remote-build.zsh`
  - 新增 `PRUNE_BUILD`：`stale` / `all` / `off`
  - 新增 `PRUNE_BUILD_NAMES`：允许清理的中间产物目录名
  - 新增 `--prune-build MODE`
  - `DELETE_EXCLUDED=1` 仍兼容，等价于 `PRUNE_BUILD=all`
- `init-project.zsh`、`remote-build.env.example`、README
  - 生成和说明这两项配置

## 架构决策

- 默认 `stale`：只清本地已消失模块的残留目录。
- 清理范围白名单默认只有 `build`，不碰 `local.properties`、`.gradle/`。
- 旧配置 `DELETE_EXCLUDED` 继续能用，新项目直接写 `PRUNE_BUILD`。

## 排除项及原因

- 不把 rsync `--delete-excluded` 传给 ignore 全表。
- 不默认清全部 `build/`。
- 不清理 `.gradle/`。

## 验证记录

- 通过：`zsh -n tools/remote-android-build/init-project.zsh`
- 通过：`zsh -n tools/remote-android-build/remote-build.zsh`
- 通过：默认 `--print-config` 输出 `PRUNE_BUILD=stale`
- 通过：`--prune-build all --print-config` 输出 `PRUNE_BUILD=all`
- 通过：配置 `PRUNE_BUILD=off` 时 `--print-config` 输出 `PRUNE_BUILD=off`
