# remote-android-build v0.1.2

## 目标

让 `init-project.zsh` 生成的 `.remote-build.zsh` 自解释，用户打开配置文件时能直接知道每个变量的含义、对应路径和修改场景。

## 变更清单

- `init-project.zsh`
  - 为 `REMOTE`、`LOCAL_ROOT`、`REMOTE_ROOT`、`TASK`、`APK_GLOB`、`LOCAL_APK_DIR`、`INSTALL_APK` 补充逐项中文注释。
  - 保留 `ADB_SERIAL`、`REMOTE_GRADLE_ARGS` 的可选项中文说明。
- `remote-build.env.example`
  - 与生成配置保持一致，补充逐项中文注释。
- `README.md`
  - 常用配置示例同步改为带注释版本。
- `CHANGELOG.md`、`versions/README.md`
  - 记录本次用户可见配置模板变化。

## 架构决策

- 注释写在配置项上方，避免行尾注释影响 shell 引号、路径或复制编辑。
- `REMOTE_ROOT` 注释明确它是可删除镜像目录，避免用户把签名、`local.properties` 等机器私有配置放进去。
- `TASK` 和 `APK_GLOB` 注释强调它们是最常需要按项目调整的字段。

## 排除项及原因

- 不自动覆盖已经存在的 `.remote-build.zsh`。该文件可能已经被用户按项目修改，覆盖风险高。
- 不引入额外配置生成器或模板引擎。当前 heredoc 足够直观，维护成本更低。
